# R з нуля — інтерактивний курс аналізу даних і математичного моделювання

Безкоштовний практичний курс мови **R** українською, що повністю працює у браузері та публікується на **GitHub Pages**. Нічого встановлювати не потрібно: R виконується прямо на сторінці завдяки [WebR](https://docs.r-wasm.org/webr/latest/) (R, скомпільований у WebAssembly).

Підхід узято з провідних інтерактивних курсів (DataCamp, Codecademy, swirl, learnr):

| Що | Як реалізовано |
|---|---|
| **Короткі конспекти** | кожен урок починається з теорії; приклади коду можна редагувати та запускати одразу |
| **Практика в редакторі** | редактор з підсвічуванням R, автозакриттям дужок, `Ctrl+Enter` — запуск, `Ctrl+Space` — підказка імен |
| **Автоперевірка** | кнопка «Перевірити» порівнює змінні, вивід, використані функції й графіки з еталоном; зрозумілі повідомлення про помилки |
| **Підказки та розв'язки** | покрокові підказки, еталонний розв'язок (без XP), поради до типових помилок R |
| **Прогрес** | XP, ранги, серія днів, досягнення, теплова карта активності; зберігається в `localStorage`, є експорт/імпорт у файл |
| **Від простого до складного** | 11 модулів курсу → банк задач трьох рівнів складності |
| **Пісочниця й довідник** | вільний редактор зі збереженням змінних і графіками; шпаргалка синтаксису з прикладами, що запускаються |

## Зміст

**11 модулів · 49 уроків · 303 завдання** + **36 задач** (легкі/середні/складні) + довідник.

1. Перші кроки в R — консоль, змінні, типи, функції
2. Вектори — створення, індексація, статистика, логіка
3. Матриці та лінійна алгебра — моделі Леонтьєва, ланцюги Маркова, МНК
4. Списки, фактори та дата-фрейми — підмножини, об'єднання, групові підсумки
5. Умови, цикли та функції — apply-родина, рекурсія, класичні алгоритми
6. Підготовка даних — CSV, пропуски, викиди, рядки, регулярні вирази, дати
7. Описова статистика та візуалізація — гістограми, boxplot, діаграми, часові ряди
8. Ймовірність і симуляції — розподіли, Монте-Карло, ЦГТ, bootstrap
9. Статистичні висновки — t-тести, χ², ANOVA, потужність, множинні порівняння
10. Регресійні моделі та прогнозування — `lm`, `glm`, діагностика, `nls`, перехресна перевірка, Холт–Вінтерс
11. Математичне моделювання — дискретні моделі, ОДУ (Ейлер, RK4, SIR, хижак–жертва), чисельні методи, оптимізація, стохастичні процеси

Усі приклади — з аналізу даних (агрономія, економіка, екологія, вбудовані набори `mtcars`, `iris`, `airquality`, `ToothGrowth`, `AirPassengers` тощо) та математичних моделей. Використовується лише **базовий R**.

## Публікація на GitHub Pages

Сайт статичний, збірка фронтенду не потрібна.

1. Злийте гілку з кодом у `main`.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, гілка `main`, каталог `/ (root)`.
3. Через хвилину сайт буде доступний за адресою `https://<користувач>.github.io/learn_R_nubip/`.

> Файл `.nojekyll` вимикає обробку Jekyll. Усі шляхи в коді відносні, тому сайт працює і з піддиректорії.

Під час першого відкриття браузер завантажує R (≈ 30 МБ з CDN `webr.r-wasm.org`), далі він кешується.

## Локальний запуск

```bash
npm install          # лише для розробки та тестів (webr для Node)
npm run serve        # http://localhost:8080
```

Відкривати `index.html` подвійним кліком не можна — потрібен HTTP-сервер (браузер блокує `fetch` з `file://`).

## Як додати або змінити урок

Уроки пишуться у звичайному Markdown з кількома додатковими конструкціями:

````markdown
# Назва уроку
> Короткий опис.

Теорія. Блок ```r — виконуваний приклад; ```r static — лише показ.

## Завдання: Назва
Текст завдання (Markdown).
```r setup
# прихований код, що виконується перед кодом користувача
x <- c(1, 2, 3)
```
```r starter
# початковий код у редакторі
```
```r solution
mean(x)
```
@hint Перша підказка
@hint Друга підказка
@check output uses=mean
@test is.numeric(m) => Повідомлення, якщо вираз у @test не істинний

## Тест: Питання
Текст питання.
- [ ] хибний варіант
- [x] правильний варіант
@explain Пояснення відповіді.
````

Параметри `@check`: `vars=a,b` — порівняти змінні з еталонними; `output` — порівняти вивід; `uses=f,g` — функції мають бути в коді; `avoid=f` — заборонені функції; `plot` — має бути побудований графік. У виразах `@test` доступні змінні користувача, `.sol` (середовище еталонного розв'язку), `.out` (вивід) та `.code` (текст коду).

У файлах `content/problems/*.md` до заголовка додається рівень `[easy]`/`[medium]`/`[hard]` та рядок `@topic Тема`.

Після змін:

```bash
npm run build        # Markdown → data/*.json
npm test             # перевірка актуальності data/ + виконання всіх розв'язків у справжньому R
```

`npm test` для кожного завдання перевіряє, що **еталонний розв'язок проходить перевірку, а стартовий код — ні**, а також що всі приклади з теорії виконуються без помилок. Ці перевірки працюють у GitHub Actions (`.github/workflows/ci.yml`).

Наскрізний тест у браузері (потрібен Playwright з Chromium):

```bash
node tests/e2e.mjs
```
