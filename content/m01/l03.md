# Функції та довідка
> Викликайте функції з аргументами, комбінуйте їх і навчіться читати довідку.

### Анатомія виклику

Функція — це іменований «інструмент»: `назва(аргумент1, аргумент2, ...)`. Аргументи можна передавати **за позицією** або **за іменем**:

```r
round(3.14159, 2)             # за позицією
round(3.14159, digits = 2)    # за іменем — зрозуміліше
round(digits = 2, x = 3.14159) # за іменем порядок не важливий
```

Багато аргументів мають **значення за замовчуванням** — їх можна пропустити:

```r
round(2.5)     # digits = 0 за замовчуванням
log(100, 10)   # основа 10
log(100)       # основа e за замовчуванням
```

### Вкладені виклики

Результат одного виклику можна одразу передати в інший:

```r
sqrt(sum(c(3, 4)^2))   # гіпотенуза трикутника з катетами 3 і 4
```

Читати треба зсередини назовні: `c(3, 4)^2` → `sum(...)` → `sqrt(...)`. Щоб код був читабельнішим, використовують **пайп** `|>` — він передає результат зліва першим аргументом у функцію справа:

```r
c(3, 4)^2 |> sum() |> sqrt()
```

### Довідка

Не пам'ятаєте, як працює функція? Запитайте R:

```r static
?mean            # довідка про функцію
help("median")   # те саме
args(round)      # лише список аргументів
example(mean)    # приклади з довідки
??"standard deviation"   # пошук за словами
```

У довідці є розділи *Usage* (синтаксис), *Arguments* (аргументи), *Value* (що повертає) та *Examples*. Прикладами в кінці корисно користуватися одразу.

### Корисні функції

```r
paste("Урожайність:", 6.2, "т/га")    # склеювання через пробіл
paste0("поле", 1:3)                    # без роздільника
nchar("аналіз даних")                  # довжина рядка
seq(0, 1, by = 0.25)                   # послідовність з кроком
rev(1:5)                               # у зворотному порядку
Sys.Date()                             # поточна дата
```

> 💡 Якщо R пише `could not find function "..."`, перевірте написання назви — R розрізняє регістр.

## Завдання: Пайп
Перепишіть обчислення `sum(sqrt(c(4, 9, 16)))` за допомогою пайпа `|>`: спочатку вектор `c(4, 9, 16)`, потім `sqrt()`, потім `sum()`.
```r starter
# c(4, 9, 16) |> ...

```
```r solution
c(4, 9, 16) |> sqrt() |> sum()
```
@hint Кожен наступний крок записується через `|>`: `c(4, 9, 16) |> sqrt() |> ...`.
@check output uses=sqrt,sum
@test grepl("|>", .code, fixed = TRUE) => Використайте оператор пайпа |>.
