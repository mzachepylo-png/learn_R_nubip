# Консоль як калькулятор
> R обчислює вирази одразу: введіть формулу — отримайте результат.

**R** — мова програмування для аналізу даних, статистики та математичного моделювання. Нею користуються вчені, аналітики, економісти та біологи по всьому світу. У цьому курсі ви писатимете код прямо в браузері: кнопка **▶ Запустити** (або `Ctrl+Enter`) виконує його, а результат з'являється під редактором.

### Арифметика

R вміє все, що вміє калькулятор. Спробуйте змінити числа та запустити приклад ще раз:

```r
2 + 3 * 4       # множення виконується раніше за додавання
(2 + 3) * 4     # дужки змінюють порядок
10 / 4          # ділення
2 ^ 10          # піднесення до степеня (також ** )
```

Окрім чотирьох дій є ще два корисні оператори:

| Оператор | Що робить | Приклад | Результат |
|---|---|---|---|
| `%/%` | цілочисельне ділення | `17 %/% 5` | `3` |
| `%%` | остача від ділення | `17 %% 5` | `2` |

```r
17 %/% 5
17 %% 5
```

> 💡 Усе після символу `#` — **коментар**. R його ігнорує, а ви можете пояснювати свій код.

### Математичні функції

Функція викликається як `назва(аргумент)`. Усі популярні функції вже вбудовані:

```r
sqrt(144)        # квадратний корінь
abs(-7.5)        # модуль
exp(1)           # e у степені 1
log(100)         # натуральний логарифм
log10(1000)      # десятковий логарифм
log(8, base = 2) # логарифм за довільною основою
round(pi, 3)     # округлення до 3 знаків; pi — вбудована константа
```

### Особливі значення

Ділення на нуль не ламає R — воно дає нескінченність `Inf`, а невизначені операції — `NaN` (Not a Number):

```r
1 / 0
0 / 0
sqrt(-1)
```

> ⚠️ Дробова частина відокремлюється **крапкою**: `3.14`, а не `3,14`.

## Завдання: Площа поля
Господарство має прямокутне поле розміром **120 м × 85 м**. Обчисліть його площу в квадратних метрах.
```r starter
# Обчисліть площу поля 120 м × 85 м

```
```r solution
120 * 85
```
@hint Площа прямокутника дорівнює добутку довжини на ширину.
@hint Запишіть вираз `120 * 85` і запустіть код.
@check output

## Завдання: Складний відсоток
Вкладник поклав **5000 грн** під **8 % річних** із щорічною капіталізацією. Яка сума буде на рахунку через **10 років**?

Формула: `сума = 5000 · (1 + 0.08)^10`.
```r starter
# сума = початковий внесок * (1 + ставка)^роки

```
```r solution
5000 * (1 + 0.08)^10
```
@hint Відсоток 8 % записуємо як `0.08`.
@hint Піднесення до степеня — оператор `^`: `(1 + 0.08)^10`.
@check output

## Завдання: Мішки зерна
Зі складу відвантажили **1000 кг** зерна. Його фасують у мішки по **35 кг**. Виведіть (по черзі, двома виразами):

1. скільки **повних** мішків вийде;
2. скільки кілограмів **залишиться**.
```r starter
# спершу кількість повних мішків, потім залишок

```
```r solution
1000 %/% 35
1000 %% 35
```
@hint Для цілої частини ділення є оператор `%/%`, для остачі — `%%`.
@check output

## Завдання: Подвоєння населення
Популяція росте на **3 % щороку**. За скільки років вона подвоїться? Час подвоєння дорівнює `ln(2) / ln(1.03)`. Обчисліть його та **округліть до 2 знаків** функцією `round()`.
```r starter
# round(вираз, 2)

```
```r solution
round(log(2) / log(1.03), 2)
```
@hint Натуральний логарифм у R — функція `log()`.
@hint Загальний вигляд: `round(log(2) / log(1.03), 2)`.
@check output uses=round,log

- [x] `5`
- [ ] `4.833333`
- [ ] `0`
