# Змінні та типи даних
> Збережіть результат під іменем і працюйте з числами, текстом та логічними значеннями.

### Присвоєння

Щоб зберегти значення, використовують оператор `<-` (стрілка). Читайте його як «покласти в»:

```r
yield <- 5.2          # урожайність, т/га
area <- 45.5          # площа, га
total <- yield * area # нова змінна обчислюється з наявних
total
```

Щоб побачити значення змінної, просто введіть її ім'я. Кілька правил для імен:

- можна літери, цифри, крапку та підкреслення: `crop_yield`, `crop.yield`;
- ім'я не може починатися з цифри;
- **регістр має значення**: `Area` і `area` — різні змінні.

> 💡 У коді R прийнято `<-`, хоча працює й `=`. Швидко набрати стрілку: `Alt` + `-` у RStudio.

```r
x <- 10
x <- x + 5   # старе значення замінюється новим
x
ls()         # які змінні існують у сесії
rm(x)        # видалити змінну
```

### Основні типи даних

| Тип | Приклад | Опис |
|---|---|---|
| `numeric` | `3.14`, `42` | дійсні числа |
| `integer` | `7L` | цілі числа (літера `L`) |
| `character` | `"пшениця"` | текст у лапках |
| `logical` | `TRUE`, `FALSE` | логічні значення |

Тип показують функції `class()` та `typeof()`; перевіряють — `is.numeric()`, `is.character()` тощо:

```r
class(3.14)
class(7L)
class("ячмінь")
class(TRUE)
is.numeric(5)
```

Особливі значення: `NA` — пропущене значення (Not Available), `NULL` — «нічого».

### Перетворення типів

Функції `as.numeric()`, `as.integer()`, `as.character()`, `as.logical()` змінюють тип. Якщо перетворити не вдається, отримаємо `NA` з попередженням:

```r
as.numeric("12.75")
as.integer(7.9)       # дробова частина відкидається
as.character(100)
as.numeric("abc")     # NA + попередження
```

### Порівняння та логіка

Результат порівняння — логічне значення:

```r
temp <- 27.5
temp > 25
temp == 27.5          # рівність — подвійний знак =
temp != 30            # «не дорівнює»
temp > 20 & temp < 30 # І (обидві умови)
temp < 0 | temp > 35  # АБО (хоча б одна)
!(temp > 25)          # заперечення
```

## Завдання: Врожай з поля
Створіть змінні `area` (площа) = `45.5` га та `yield_per_ha` (урожайність) = `6.2` т/га. Потім у змінну `total` запишіть загальний збір (`area * yield_per_ha`).
```r starter
# створіть змінні area, yield_per_ha та total

```
```r solution
area <- 45.5
yield_per_ha <- 6.2
total <- area * yield_per_ha
```
@hint Присвоєння виглядає так: `area <- 45.5`.
@hint `total <- area * yield_per_ha` — після того, як створено обидві змінні.
@check vars=area,yield_per_ha,total

## Завдання: Класи змінних
Створіть три змінні: `crop` — текст `"пшениця"`, `n_fields` — ціле число `12L`, `irrigated` — `TRUE`. Потім виведіть клас кожної з них (по черзі: `crop`, `n_fields`, `irrigated`) функцією `class()`.
```r starter
# створіть змінні й виведіть їхні класи

```
```r solution
crop <- "пшениця"
n_fields <- 12L
irrigated <- TRUE
class(crop)
class(n_fields)
class(irrigated)
```
@hint Текст беремо в лапки, ціле число записуємо з літерою `L`.
@hint Три окремі виклики: `class(crop)`, `class(n_fields)`, `class(irrigated)`.
@check vars=crop,n_fields,irrigated output uses=class

## Завдання: Текст у число
Ціна зерна записана текстом. Перетворіть `price_text` на число та збільште ціну на 10 % — результат збережіть у змінній `price`.
```r setup
price_text <- "12.75"
```
```r starter
# price_text вже існує

```
```r solution
price <- as.numeric(price_text) * 1.1
```
@hint `as.numeric()` перетворює текст на число.
@hint Збільшення на 10 % — це множення на `1.1`.
@check vars=price uses=as.numeric

## Завдання: Погодні умови
Температура повітря `temp <- 27.5`. Створіть логічні змінні:

- `is_hot` — чи температура більша за 25;
- `is_comfortable` — чи температура від 18 до 25 включно.
```r setup
temp <- 27.5
```
```r starter
# is_hot і is_comfortable

```
```r solution
is_hot <- temp > 25
is_comfortable <- temp >= 18 & temp <= 25
```
@hint Порівняння дає `TRUE` або `FALSE`: `temp > 25`.
@hint Для «від 18 до 25» поєднайте дві умови оператором `&`.
@check vars=is_hot,is_comfortable
