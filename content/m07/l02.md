# Базова графіка
> Побудова діаграм: plot, lines, points, abline, legend.

Функція `plot()` — універсальна: залежно від типу даних вона малює діаграму розсіювання, лінію або щось інше. Графік з'являється під редактором.

```r
plot(cars$speed, cars$dist,
     main = "Гальмівний шлях",
     xlab = "Швидкість, миль/год",
     ylab = "Шлях, футів",
     pch = 19, col = "steelblue")
```

### Найважливіші параметри

| Параметр | Що робить |
|---|---|
| `main`, `xlab`, `ylab` | заголовок, підписи осей |
| `type` | `"p"` точки, `"l"` лінія, `"b"` обидва, `"h"` стовпчики |
| `pch` | символ точки (1–25, `19` — суцільна) |
| `col` | колір: `"red"`, `"#2a9d8f"`, `rgb(...)` |
| `lwd`, `lty` | товщина й тип лінії |
| `cex` | масштаб символів |
| `xlim`, `ylim` | межі осей |

### Додавання елементів

Нові шари малюються поверх наявного графіка:

```r
years <- 2015:2024
yield <- c(5.2, 5.5, 5.1, 5.9, 6.2, 6.0, 6.5, 6.4, 6.9, 7.1)
plot(years, yield, type = "b", pch = 16, col = "darkgreen",
     main = "Урожайність за роками", xlab = "Рік", ylab = "т/га")
abline(h = mean(yield), lty = 2, col = "grey40")         # горизонтальна лінія
abline(lm(yield ~ years), col = "red", lwd = 2)          # лінія регресії
text(2016, mean(yield) + 0.2, "середнє")
```

### Кілька ліній і легенда

```r
x <- 1:10
plot(x, x^2, type = "l", col = "blue", lwd = 2, ylab = "y")
lines(x, 3 * x, col = "red", lwd = 2)
points(x, x^1.5, pch = 17, col = "darkgreen")
legend("topleft", legend = c("x²", "3x", "x^1.5"),
       col = c("blue", "red", "darkgreen"), lwd = c(2, 2, NA), pch = c(NA, NA, 17))
```

### Кілька графіків поруч і графік функції

```r
par(mfrow = c(1, 2))                       # 1 рядок, 2 графіки
curve(sin, 0, 2 * pi, main = "sin")
curve(x^2 - 3 * x, -1, 4, main = "парабола")
par(mfrow = c(1, 1))
```

> 💡 Збережіть графік на своєму комп'ютері через `png("fig.png"); plot(...); dev.off()`. У браузерному курсі зображення просто відображаються під кодом.

## Завдання: Дві лінії та легенда
Намалюйте графіки `x^2` (синім) і `3 * x` (червоним) для `x` від 1 до 10: спочатку `plot(..., type = "l")`, потім `lines()`, а також додайте `legend()`.
```r setup
x <- 1:10
```
```r starter
# plot(x, x^2, type = "l", col = "blue")

```
