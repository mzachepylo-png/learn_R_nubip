# Зв'язки між змінними та часові ряди
> Матриці діаграм розсіювання, кольори за групами та графіки рядів у часі.

### Колір за категорією

```r
plot(iris$Sepal.Length, iris$Petal.Length,
     col = iris$Species, pch = 19,
     xlab = "Довжина чашолистка", ylab = "Довжина пелюстки")
legend("topleft", legend = levels(iris$Species), col = 1:3, pch = 19)
```

Фактор `Species` автоматично перетворюється на кольори палітри (1 — чорний, 2 — червоний, 3 — зелений).

### Матриця діаграм

```r
pairs(iris[, 1:4], col = iris$Species, pch = 19)
```

### Кореляційна матриця

```r
round(cor(mtcars[, c("mpg", "wt", "hp", "qsec")]), 2)
```

### Часові ряди

Об'єкти класу `ts` знають про час, тому `plot` малює їх як лінії:

```r
class(AirPassengers)
start(AirPassengers); end(AirPassengers); frequency(AirPassengers)
plot(AirPassengers, main = "Пасажири авіаліній (1949–1960)", ylab = "тис.")
```

Ряд має тренд і зростаючу амплітуду сезонності — логарифм вирівнює її:

```r
plot(log(AirPassengers))
```

Накладаємо середнє та згладжування:

```r
plot(Nile, main = "Стік Нілу")
abline(h = mean(Nile), lty = 2, col = "red")
lines(lowess(time(Nile), Nile), col = "blue", lwd = 2)
```

> 💡 Висока кореляція ще не означає причинного зв'язку: дві величини можуть мати спільну причину або співпасти випадково.

## Завдання: Кольорова діаграма
Побудуйте діаграму розсіювання `Sepal.Length` (вісь x) та `Petal.Length` (вісь y) із набору `iris`, пофарбувавши точки за видом (`col = iris$Species`).
```r starter
# plot(..., col = ...)

```
```r solution
plot(iris$Sepal.Length, iris$Petal.Length, col = iris$Species, pch = 19)
```
@hint `col = iris$Species`.
@check plot uses=plot
@test grepl("Species", .code) && grepl("col", .code) => Розфарбуйте точки за видом через col = iris$Species.

# pairs(...)

## Завдання: Кореляційна матриця
Виведіть кореляційну матрицю стовпців `mpg`, `wt` та `hp` набору `mtcars`, округлену до 2 знаків.
```r starter
# round(cor(...), 2)

```
```r solution
round(cor(mtcars[, c("mpg", "wt", "hp")]), 2)
```
@hint `cor()` приймає дата-фрейм із числових стовпців.
@check output uses=cor,round

## Завдання: Часовий ряд
Побудуйте графік ряду `Nile` та додайте червону пунктирну лінію середнього значення.
