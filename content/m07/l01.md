# Описова статистика
> Центр, розкид, форма розподілу та зв'язок між змінними — кількома числами.

Перед моделюванням треба зрозуміти дані. Для прикладів візьмемо вбудований набір `mtcars` (32 автомобілі):

```r
x <- mtcars$mpg          # витрата пального, миль на галон
mean(x)                  # середнє
median(x)                # медіана — стійка до викидів
sd(x); var(x)            # розкид
range(x); IQR(x)         # діапазон і міжквартильний розмах
quantile(x, c(0.1, 0.9))
```

### Міри центру та розкиду

| Показник | Функція | Коли корисний |
|---|---|---|
| середнє | `mean` | симетричні дані |
| медіана | `median` | є викиди / асиметрія |
| мода | через `table` | категорії, дискретні значення |
| стандартне відхилення | `sd` | розкид у тих самих одиницях |
| коефіцієнт варіації | `sd / mean` | порівняння розкиду різних величин |
| IQR | `IQR` | стійкий розкид |

Мода — найчастіше значення; готової функції немає:

```r
tab <- table(mtcars$cyl)
tab
names(which.max(tab))
```

Коефіцієнт варіації (у відсотках):

```r
100 * sd(x) / mean(x)
```

### Зв'язок: кореляція

```r
cor(mtcars$mpg, mtcars$wt)                         # Пірсон
cor(mtcars$mpg, mtcars$wt, method = "spearman")    # рангова
round(cor(mtcars[, c("mpg", "wt", "hp")]), 2)      # матриця
```

### Зважене середнє та форма розподілу

```r
grades <- c(90, 75, 82)
w <- c(0.5, 0.2, 0.3)
weighted.mean(grades, w)

# коефіцієнт асиметрії (вручну)
m <- mean(x)
mean((x - m)^3) / mean((x - m)^2)^1.5
```

Додатна асиметрія — довгий «хвіст» праворуч.

## Завдання: Центр і розкид
Для `mtcars$mpg` обчисліть середнє `m`, медіану `md` та стандартне відхилення `s`.
```r starter
# m <- ...
# md <- ...
# s <- ...

```
```r solution
m <- mean(mtcars$mpg)
md <- median(mtcars$mpg)
s <- sd(mtcars$mpg)
```
@hint `mean`, `median`, `sd`.
@check vars=m,md,s
