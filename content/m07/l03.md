# Розподіли: гістограми та коробчасті діаграми
> Подивіться на форму даних: гістограма, щільність, boxplot, стовпчики, Q–Q.

### Гістограма й щільність

```r
x <- faithful$waiting     # інтервали між виверженнями гейзера, хв
hist(x, breaks = 20, col = "lightblue", border = "white",
     main = "Інтервали між виверженнями", xlab = "хв")
```

Щоб накласти криву щільності, гістограму масштабують до частот-щільності (`freq = FALSE`):

```r
hist(x, freq = FALSE, breaks = 20, col = "grey90", main = "")
lines(density(x), col = "red", lwd = 2)
```

Дані двогорбі (бімодальні): у них дві групи.

### Коробчасті діаграми

Коробка показує квартили, «вуса» — діапазон без викидів, окремі точки — викиди.

```r
boxplot(len ~ supp, data = ToothGrowth,
        col = c("orange", "lightgreen"),
        main = "Ріст зубів за способом введення", ylab = "довжина")
boxplot(mpg ~ cyl, data = mtcars, xlab = "циліндри", ylab = "mpg")
```

Формула `y ~ група` розбиває `y` за групами.

### Стовпчики для категорій

```r
counts <- table(mtcars$cyl)
barplot(counts, col = "steelblue", main = "Автомобілі за циліндрами")
barplot(table(mtcars$gear, mtcars$cyl), beside = TRUE, legend = TRUE)
```

### Розраховані підсумки гістограми

`hist(..., plot = FALSE)` повертає дані: межі інтервалів і кількості спостережень:

```r
h <- hist(x, breaks = seq(40, 100, by = 10), plot = FALSE)
h$breaks
h$counts
```

### Q–Q графік: чи нормальні дані?

Якщо точки лежать уздовж прямої, розподіл близький до нормального:

```r
qqnorm(x)
qqline(x, col = "red")
```

## Тест: Вуса boxplot
Що позначають окремі точки за межами «вусів» на коробчастій діаграмі?
- [ ] середнє значення
- [ ] межі довірчого інтервалу
- [x] потенційні викиди
- [ ] медіану
@explain Вуси сягають найдальших значень у межах 1.5·IQR від квартилів; точки за ними — потенційні викиди.
