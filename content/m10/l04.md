# Логістична регресія
> Моделювання ймовірності події: так/ні, хвороба/здоров'я, сходи/не зійшло.

Коли відгук бінарний (0/1), лінійна модель може давати «ймовірності» поза `[0, 1]`. Логістична регресія моделює **логіт** (логарифм шансів):

`ln(p / (1 − p)) = β₀ + β₁·x`

```r
fit <- glm(am ~ wt, data = mtcars, family = binomial)
summary(fit)
coef(fit)
```

### Ймовірності та прогноз

```r
predict(fit, newdata = data.frame(wt = 3), type = "response")   # P(am = 1 | wt = 3)
p <- fitted(fit)                                                # ймовірності для даних
head(round(p, 3))

plot(mtcars$wt, mtcars$am, pch = 19, xlab = "Вага", ylab = "P(ручна коробка)")
curve(predict(fit, data.frame(wt = x), type = "response"), add = TRUE, col = "red", lwd = 2)
```

### Відношення шансів

`exp(β)` — у скільки разів змінюються **шанси** при зростанні `x` на одиницю:

```r
exp(coef(fit))
exp(confint.default(fit))
```

### Якість класифікації

```r
pred <- ifelse(fitted(fit) > 0.5, 1, 0)
cm <- table(Факт = mtcars$am, Прогноз = pred)
cm
mean(pred == mtcars$am)                  # точність (accuracy)
cm[2, 2] / sum(cm[2, ])                  # чутливість (sensitivity)
cm[1, 1] / sum(cm[1, ])                  # специфічність (specificity)
```

> 💡 Поріг 0.5 — не закон: у медицині для скринінгу часто знижують поріг, щоб не пропускати хворих (ціною хибних тривог).

## Завдання: Логістична модель
Побудуйте модель `am ~ wt` з `family = binomial` на даних `mtcars` (змінна `fit`) та збережіть коефіцієнти у `b`.
```r starter

```

@check vars=b uses=glm

## Завдання: Точність класифікації
Класифікуйте автомобілі за порогом 0.5: `pred` — 1, якщо ймовірність (`fitted(fit)`) більша за 0.5, інакше 0. Збережіть точність `acc` — частку правильних прогнозів.
```r setup
fit <- glm(am ~ wt, data = mtcars, family = binomial)
```
```r starter
# pred <- ifelse(...)
# acc <- ...

```
```r solution
pred <- ifelse(fitted(fit) > 0.5, 1, 0)
acc <- mean(pred == mtcars$am)
```
@hint Правильні прогнози — `pred == mtcars$am`.
@check vars=acc

## Завдання: Чутливість і специфічність
За таблицею помилок `cm` (рядки — факт 0/1, стовпці — прогноз 0/1) обчисліть чутливість `sens` (частка виявлених позитивних) та специфічність `spec` (частка виявлених негативних).
```r setup
cm <- matrix(c(50, 10, 5, 35), nrow = 2, byrow = TRUE, dimnames = list(Факт = c("0", "1"), Прогноз = c("0", "1")))
```
```r starter
# sens <- ...
# spec <- ...

```
```r solution
sens <- cm[2, 2] / sum(cm[2, ])
spec <- cm[1, 1] / sum(cm[1, ])
```
@hint Чутливість — правильно виявлені одиниці серед усіх фактичних одиниць (рядок 2).
@check vars=sens,spec

- [ ] ймовірність події подвоюється
- [x] при зростанні `x` на одиницю шанси `p/(1−p)` збільшуються вдвічі
- [ ] модель правильно класифікує 200 % випадків
- [ ] `x` не впливає на результат
