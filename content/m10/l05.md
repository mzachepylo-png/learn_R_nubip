# Нелінійні моделі та перевірка прогнозів
> Поліноми, експоненціальне зростання, nls та оцінка якості на нових даних.

### Поліноміальна регресія

Модель лінійна за параметрами, навіть коли містить `x²`:

```r
fit_q <- lm(dist ~ speed + I(speed^2), data = cars)
coef(fit_q)
plot(cars, pch = 19)
xs <- seq(4, 25, length.out = 100)
lines(xs, predict(fit_q, data.frame(speed = xs)), col = "red", lwd = 2)
```

### Експоненціальне зростання

Для `y = a·e^(b·t)` логарифмування дає лінійну модель `ln y = ln a + b·t`:

```r
set.seed(1)
t <- 0:10
y <- 5 * exp(0.25 * t) * exp(rnorm(11, 0, 0.05))
fit_log <- lm(log(y) ~ t)
coef(fit_log)             # ln a та b
exp(coef(fit_log)[1])     # a
```

### Нелінійні найменші квадрати (`nls`)

`nls` підбирає параметри довільної формули. Потрібні **початкові значення**:

```r
fit_nls <- nls(y ~ a * exp(b * t), start = list(a = 3, b = 0.2))
coef(fit_nls)
```

### Розбиття на навчальну й тестову вибірки

Якість моделі потрібно оцінювати на даних, яких вона не бачила. Мірою помилки є RMSE — корінь із середнього квадрата помилки:

```r
set.seed(1)
idx <- sample(nrow(cars), 35)
train <- cars[idx, ]
test <- cars[-idx, ]
fit <- lm(dist ~ speed, data = train)
sqrt(mean((test$dist - predict(fit, test))^2))
```

### Перехресна перевірка «одного виключеного»

```r
errs <- sapply(1:nrow(cars), function(i) {
  m <- lm(dist ~ speed, data = cars[-i, ])
  (cars$dist[i] - predict(m, cars[i, ]))^2
})
sqrt(mean(errs))
```

> ⚠️ **Перенавчання**: складна модель ідеально підганяється під навчальні дані, але погано прогнозує нові. Порівнюйте моделі за помилкою на тестових даних.

## Завдання: Навчальна та тестова вибірки
Виберіть випадково 35 рядків набору `cars` як навчальні (`set.seed(1)`, `sample(nrow(cars), 35)`), решта — тест. Побудуйте на навчальних модель `dist ~ speed` та обчисліть `rmse` на тестових.
```r starter
# set.seed(1)
# idx <- ...
# train <- ...
# test <- ...
# fit <- ...
# rmse <- ...

```
```r solution
set.seed(1)
idx <- sample(nrow(cars), 35)
train <- cars[idx, ]
test <- cars[-idx, ]
fit <- lm(dist ~ speed, data = train)
rmse <- sqrt(mean((test$dist - predict(fit, test))^2))
```
@hint RMSE: корінь із середнього квадрата різниць факту й прогнозу.
@check vars=rmse

## Завдання: Перехресна перевірка
Обчисліть RMSE методом «одного виключеного» для моделі `dist ~ speed` на `cars`: для кожного `i` побудуйте модель без `i`-го рядка й оцініть помилку на ньому. Результат — `cv_rmse`.
```r starter
# errs <- sapply(...)
# cv_rmse <- ...

```
```r solution
errs <- sapply(1:nrow(cars), function(i) {
  m <- lm(dist ~ speed, data = cars[-i, ])
  (cars$dist[i] - predict(m, cars[i, ]))^2
})
cv_rmse <- sqrt(mean(errs))
```
@hint `cars[-i, ]` — усі рядки, крім `i`-го.
@check vars=cv_rmse
