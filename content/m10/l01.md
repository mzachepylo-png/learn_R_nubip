# Проста лінійна регресія
> Модель `y = β₀ + β₁·x + ε`: оцінка, перевірка якості та прогноз.

Регресія описує, як змінюється відгук `y` зі зміною пояснювальної змінної `x`. Приклад: гальмівний шлях автомобіля (`dist`, футів) залежно від швидкості (`speed`, миль/год) — набір `cars`.

```r
plot(cars$speed, cars$dist, pch = 19, xlab = "Швидкість", ylab = "Шлях")
fit <- lm(dist ~ speed, data = cars)
abline(fit, col = "red", lwd = 2)
fit
```

Формула `dist ~ speed` читається «dist залежить від speed».

### Огляд моделі

```r
summary(fit)
coef(fit)                         # β₀ і β₁
summary(fit)$r.squared            # R² — частка поясненої дисперсії
summary(fit)$sigma                # залишкова стандартна похибка
confint(fit)                      # довірчі інтервали коефіцієнтів
```

Коефіцієнт при `speed` означає: зі зростанням швидкості на 1 милю/год очікуваний шлях збільшується на `β₁` футів.

### Прогноз

```r
new <- data.frame(speed = c(10, 20, 25))
predict(fit, newdata = new)
predict(fit, new, interval = "confidence")   # інтервал для середнього
predict(fit, new, interval = "prediction")   # інтервал для окремого спостереження
```

### Залишки

```r
head(resid(fit))
head(fitted(fit))
sum(resid(fit)^2)       # сума квадратів залишків (її МНК мінімізує)
```

> ⚠️ Прогнозуйте лише в межах діапазону даних. Екстраполяція (наприклад, `speed = 100`) може дати безглуздий результат.

## Тест: Інтерпретація нахилу
Модель `dist = −17.6 + 3.93·speed`. Що означає коефіцієнт 3.93?
- [ ] при нульовій швидкості шлях дорівнює 3.93
- [x] при зростанні швидкості на 1 милю/год очікуваний шлях збільшується приблизно на 3.93 фута
- [ ] 3.93 % змінності шляху пояснюється швидкістю
- [ ] швидкість і шлях збігаються на 3.93 %
@explain Нахил — середня зміна `y` при збільшенні `x` на одиницю. Частку поясненої змінності показує R².
