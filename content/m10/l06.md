# Часові ряди
> Тренд, сезонність, декомпозиція та прогноз Холта–Вінтерса.

Часовий ряд — спостереження, впорядковані в часі. У R для них є клас `ts`:

```r
y <- ts(c(12, 15, 14, 18, 21, 25, 24, 27, 26, 30, 33, 35),
        start = c(2023, 1), frequency = 12)
y
frequency(y); start(y); end(y)
plot(y, type = "o")
```

Класичний приклад — набір `AirPassengers`: щомісячна кількість авіапасажирів (тис.) 1949–1960.

```r
plot(AirPassengers)
window(AirPassengers, start = c(1955, 1), end = c(1955, 12))
aggregate(AirPassengers, FUN = sum)       # річні суми
cycle(AirPassengers)[1:12]                # номер місяця
```

### Декомпозиція

Ряд = тренд + сезонність + залишок. Амплітуда сезонності росте разом із рівнем, тому підходить мультиплікативна модель:

```r
dec <- decompose(AirPassengers, type = "multiplicative")
plot(dec)
round(dec$figure, 3)       # сезонні індекси по місяцях
```

Червень–серпень мають індекси вище 1 — літній пік.

### Стаціонарність і автокореляція

Диференціювання логарифмів дає приблизно стаціонарний ряд відносних змін:

```r
d <- diff(log(AirPassengers))
plot(d)
acf(d, plot = FALSE)$acf[1:4]
acf(d)                      # коефіцієнти автокореляції на різних лагах
```

### Прогнозування за Холтом–Вінтерсом

```r
hw <- HoltWinters(AirPassengers, seasonal = "multiplicative")
fc <- predict(hw, n.ahead = 12)
plot(hw, fc)
round(fc, 0)
```

> 💡 Перевіряйте прогноз на «відкладеній» частині: виділіть останній рік як тест, навчіть модель на попередніх роках і порівняйте помилку.

## Завдання: Прогноз Холта–Вінтерса
Підгоніть модель `HoltWinters` з мультиплікативною сезонністю до `AirPassengers` (змінна `hw`) і зробіть прогноз на 12 місяців уперед у змінну `fc`.
```r starter

```
```r solution

```
@hint `predict(hw, n.ahead = 12)`.
@check uses=HoltWinters,predict
@test length(fc) == 12 && isTRUE(all.equal(as.numeric(fc), as.numeric(.sol$fc), tolerance = 1e-3)) => Прогноз має містити 12 значень (за 1961 рік, ≈ 450–600 тис. пасажирів).
