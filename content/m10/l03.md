# Діагностика моделі
> Чи можна довіряти регресії? Аналіз залишків, впливових точок і мультиколінеарності.

Припущення лінійної моделі: лінійність зв'язку, незалежність і нормальність залишків, сталість їх дисперсії (гомоскедастичність).

```r
fit <- lm(mpg ~ wt + hp, data = mtcars)
par(mfrow = c(2, 2))
plot(fit)                 # чотири стандартні діагностичні графіки
par(mfrow = c(1, 1))
```

### Залишки проти прогнозів

Хмара без закономірностей навколо нуля — добре. Крива — порушена лінійність; «лійка» — неоднорідна дисперсія.

```r
plot(fitted(fit), resid(fit), pch = 19, xlab = "Прогноз", ylab = "Залишки")
abline(h = 0, lty = 2, col = "red")
```

### Нормальність залишків

```r
qqnorm(resid(fit)); qqline(resid(fit))
shapiro.test(resid(fit))
```

### Впливові спостереження

```r
cd <- cooks.distance(fit)
which.max(cd)                  # найвпливовіша точка
head(sort(cd, decreasing = TRUE), 3)
hatvalues(fit)[1:3]            # важелі
```

Значення відстані Кука, що помітно перевищують решту (наприклад, > 4/n), заслуговують на перевірку: помилка даних чи справжній екстрем?

### Мультиколінеарність

Коли пояснювальні змінні сильно корелюють, оцінки коефіцієнтів нестабільні. Коефіцієнт підсилення дисперсії: `VIF = 1 / (1 − R²ⱼ)`, де `R²ⱼ` — R² регресії *j*-ї змінної на решту:

```r
cor(mtcars$wt, mtcars$hp)
1 / (1 - summary(lm(wt ~ hp, data = mtcars))$r.squared)
```

VIF > 5–10 — ознака проблеми.

### Перетворення змінних

Логарифмування часто стабілізує дисперсію та лінеаризує зв'язок:

```r
summary(lm(dist ~ speed, data = cars))$r.squared
summary(lm(log(dist) ~ log(speed), data = cars))$r.squared
```

## Завдання: VIF вручну
Обчисліть VIF для `wt` у моделі з предикторами `wt` і `hp`: `1 / (1 − R²)`, де R² — з регресії `wt ~ hp`. Результат — `vif`.
```r starter
# vif <- ...

```
```r solution

```
@hint R² береться з `summary(lm(wt ~ hp, data = mtcars))$r.squared`.
@check vars=vif
