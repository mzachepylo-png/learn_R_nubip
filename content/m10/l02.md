# Множинна регресія
> Кілька пояснювальних змінних, категорії, взаємодії та вибір моделі.

Додаємо змінні у формулу через `+`. Модель витрати пального `mpg` від ваги, потужності та типу коробки:

```r
fit1 <- lm(mpg ~ wt, data = mtcars)
fit2 <- lm(mpg ~ wt + hp, data = mtcars)
summary(fit2)
```

Кожен коефіцієнт — вплив змінної **за умови, що інші незмінні**.

### Категоріальні змінні

Фактор автоматично перетворюється на «фіктивні» (dummy) змінні:

```r
fit3 <- lm(mpg ~ wt + factor(am), data = mtcars)
coef(fit3)
```

`factor(am)1` — зсув для автомобілів із ручною коробкою відносно автоматичної (базовий рівень).

### Взаємодії

`wt * am` означає `wt + am + wt:am` — нахил за вагою може відрізнятися між групами:

```r
fit4 <- lm(mpg ~ wt * am, data = mtcars)
coef(fit4)
```

Перетворення змінних усередині формули беруть в `I()`: `lm(y ~ x + I(x^2))`.

### Порівняння моделей

```r
summary(fit1)$adj.r.squared         # скоригований R² штрафує за зайві змінні
summary(fit2)$adj.r.squared
anova(fit1, fit2)                   # F-тест вкладених моделей
AIC(fit1, fit2)                     # менше — краще
BIC(fit1, fit2)
```

> 💡 Не додавайте змінні лише заради зростання R²: звичайний R² завжди збільшується. Дивіться на скоригований R², AIC/BIC та перехресну перевірку.

## Завдання: Скоригований R²
Порівняйте моделі `fit1` (`mpg ~ wt`) та `fit2` (`mpg ~ wt + hp`): збережіть їх скоригований R² у `adj1` та `adj2`.
```r setup
fit1 <- lm(mpg ~ wt, data = mtcars)
fit2 <- lm(mpg ~ wt + hp, data = mtcars)
```
```r starter
# adj1 <- ...
# adj2 <- ...

```
```r solution
adj1 <- summary(fit1)$adj.r.squared
adj2 <- summary(fit2)$adj.r.squared
```
@hint Елемент `adj.r.squared` у `summary()`.
@check vars=adj1,adj2

## Завдання: F-тест вкладених моделей
Виконайте `anova(fit1, fit2)` та збережіть p-значення в `p_anova` (друге значення стовпця `"Pr(>F)"`).
```r setup
fit1 <- lm(mpg ~ wt, data = mtcars)
fit2 <- lm(mpg ~ wt + hp, data = mtcars)
```
```r starter
# p_anova <- anova(...)[["Pr(>F)"]][2]

```
```r solution
p_anova <- anova(fit1, fit2)[["Pr(>F)"]][2]
```
@hint Таблиця `anova` має стовпець `Pr(>F)`.
@check vars=p_anova uses=anova

## Завдання: Вибір за AIC
Обчисліть AIC обох моделей та збережіть у `best` номер (1 або 2) моделі з **меншим** AIC (використайте `which.min`).
```r setup
fit1 <- lm(mpg ~ wt, data = mtcars)
fit2 <- lm(mpg ~ wt + hp, data = mtcars)
```
```r starter
# best <- which.min(c(...))

```
```r solution
best <- which.min(c(AIC(fit1), AIC(fit2)))
```
@hint `c(AIC(fit1), AIC(fit2))` — вектор, у якому шукаємо мінімум.
@check vars=best uses=AIC,which.min

## Тест: Скоригований R²
Чому для порівняння моделей із різною кількістю змінних краще скоригований R², а не звичайний?
- [ ] він завжди більший
- [x] звичайний R² не зменшується при додаванні змінних, а скоригований штрафує за зайві
- [ ] скоригований R² не залежить від даних
- [ ] звичайний R² не можна обчислити для кількох змінних
@explain Додавання будь-якої змінної не знижує R². Скоригований R² враховує кількість параметрів і може зменшитися, якщо змінна не покращує модель.
