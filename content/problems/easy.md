## Завдання: Спекотні дні [easy]
@topic Аналіз даних
У наборі `airquality` стовпець `Temp` — максимальна денна температура (°F) у Нью-Йорку за травень–вересень 1973 року. Обчисліть:

- `mean_t` — середню температуру;
- `n_hot` — кількість днів, коли температура була **вищою за 85 °F**.
```r starter
# mean_t <- ...
# n_hot <- ...

```
```r solution
mean_t <- mean(airquality$Temp)
n_hot <- sum(airquality$Temp > 85)
```
@hint У стовпці `Temp` немає пропусків, тож `na.rm` не потрібен.
@hint Кількість днів — `sum()` від логічного вектора.
@check vars=mean_t,n_hot

## Завдання: Індекс маси тіла [easy]
@topic Аналіз даних
У наборі `women` зріст (`height`, дюйми) і вага (`weight`, фунти) жінок. Обчисліть вектор `bmi` — ІМТ, округлений до 1 знака: `вага_кг / зріст_м²`, де `1 фунт = 0.453592 кг`, `1 дюйм = 0.0254 м`.
```r starter
# bmi <- ...

```
```r solution

```
@hint Спочатку переведіть вагу в кг, а зріст у метри.
@check vars=bmi

## Завдання: Z-оцінка автомобіля [easy]
@topic Статистика
Скільки стандартних відхилень відділяє потужність `hp` автомобіля `"Maserati Bora"` від середньої потужності всіх автомобілів у `mtcars`? Збережіть у `z`.

## Завдання: Сентинельні значення [easy]
@topic Очищення даних
Прилад записує `-999`, коли вимір відсутній. Замініть їх на `NA` і обчисліть середнє решти значень: змінна `mean_ok`. Вектор `x` після заміни має залишитися у змінній `x`.

```r setup
x <- c(5, -999, 7, 6, -999, 8)
```


@check vars=x,mean_ok

## Завдання: Квадратне рівняння [easy]
@topic Математика
Розв'яжіть рівняння `x² − 3x + 2 = 0` через дискримінант. Збережіть коріння, впорядковане за зростанням, у вектор `roots`.
```r setup
a <- 1
b <- -3
c0 <- 2
```
```r starter
# D <- ...
# roots <- ...

```
```r solution
D <- b^2 - 4 * a * c0
roots <- sort(c((-b - sqrt(D)) / (2 * a), (-b + sqrt(D)) / (2 * a)))
```
@hint Дискримінант `D = b² − 4ac`; корені `(−b ± √D) / 2a`.
@check vars=roots

## Завдання: Час подвоєння [easy]
@topic Моделювання
Вклад росте на 7 % щороку. Скільки повних років потрібно, щоб сума **стала не меншою за подвійну**? Збережіть у `years` (цілий результат: `ceiling` від `log(2) / log(1.07)`).
```r starter
# years <- ...

```
```r solution
years <- ceiling(log(2) / log(1.07))
```
@hint Із `1.07^t ≥ 2` маємо `t ≥ ln 2 / ln 1.07`.
@check vars=years

## Завдання: Паліндром [easy]
@topic Алгоритми
Напишіть функцію `is_pal(s)`, яка повертає `TRUE`, якщо рядок читається однаково в обидва боки (регістр і пробіли ігноруються).
```r starter
# is_pal <- function(s) {
#
# }

```
```r solution
is_pal <- function(s) {
  t <- gsub(" ", "", tolower(s))
  chars <- strsplit(t, "")[[1]]
  identical(chars, rev(chars))
}
```
@hint Приберіть пробіли `gsub(" ", "", ...)`, розбийте на символи й порівняйте з `rev()`.
@check uses=function
@test is.function(is_pal) && isTRUE(is_pal("Шалаш")) && isTRUE(is_pal("А роза упала на лапу Азора")) && isTRUE(is_pal("кайак")) => Рядки «Шалаш», «А роза упала на лапу Азора» та «кайак» — паліндроми.
@test is.function(is_pal) && !isTRUE(is_pal("статистика")) && isTRUE(is_pal("R")) => «статистика» не паліндром, а однолітерний рядок «R» — паліндром.

## Завдання: Лінійна інтерполяція [easy]
@topic Моделювання
Відомі виміри висоти рослини: на 10-й день 12 см, на 20-й — 30 см. Оцініть висоту на 14-й день лінійною інтерполяцією: змінна `h14`.
```r starter
# h14 <- ...

```
```r solution

```
@hint Функція `approx(x, y, xout = ...)` або формула прямої.
@check vars=h14
