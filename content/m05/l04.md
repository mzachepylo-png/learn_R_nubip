# Функціональний підхід: apply-родина
> Замість циклів — застосовуйте функції до цілих колекцій.

```r
fields <- list(
  A = c(5.1, 5.4, 4.9, 5.8),
  B = c(6.3, 6.8, 6.1, 7.0),
  C = c(5.7, 5.5, 6.0)
)
```

### lapply, sapply, vapply

| Функція | Результат |
|---|---|
| `lapply(x, f)` | завжди список |
| `sapply(x, f)` | спрощує до вектора/матриці, якщо можливо |
| `vapply(x, f, тип)` | як `sapply`, але з перевіркою типу — надійніше |

```r
lapply(fields, mean)
sapply(fields, mean)
vapply(fields, function(v) sd(v) / mean(v), numeric(1))   # коефіцієнт варіації
sapply(fields, range)                                      # матриця 2 × 3
```

### Filter, Map, Reduce

```r
Filter(function(v) mean(v) > 5.5, fields)       # лише «хороші» поля
Map(function(v, n) v * n, list(1:3, 4:6), c(10, 100))
Reduce(`+`, 1:5)                                # 15
Reduce(`+`, 1:5, accumulate = TRUE)             # накопичення: 1 3 6 10 15
```

### mapply та do.call

```r
mapply(function(a, b) a * b, c(1, 2, 3), c(10, 20, 30))
rows <- list(c(1, 2, 3), c(4, 5, 6))
do.call(rbind, rows)       # rbind(rows[[1]], rows[[2]])
```

`do.call(f, список)` викликає функцію, передавши елементи списку як аргументи — зручно, щоб скласти купу векторів у матрицю чи таблицю.

> 💡 `sapply` зручний для інтерактивної роботи, а `vapply` — для надійного коду: він одразу повідомить, якщо результат має неочікуваний тип чи довжину.

## Завдання: Середні за полями
Для списку `fields` створіть вектор `means` — середнє для кожного елемента (`sapply`).
```r setup
fields <- list(A = c(5.1, 5.4, 4.9, 5.8), B = c(6.3, 6.8, 6.1, 7.0), C = c(5.7, 5.5, 6.0))
```
```r starter
# means <- sapply(...)

```
```r solution
means <- sapply(fields, mean)
```
@hint `sapply(fields, mean)`.
@check vars=means uses=sapply

## Завдання: Коефіцієнт варіації
Обчисліть `cv` — коефіцієнт варіації `sd(v) / mean(v)` для кожного поля за допомогою `vapply` (результат — одне число для кожного елемента, тип `numeric(1)`).
```r setup
fields <- list(A = c(5.1, 5.4, 4.9, 5.8), B = c(6.3, 6.8, 6.1, 7.0), C = c(5.7, 5.5, 6.0))
```
```r starter
# cv <- vapply(fields, ..., numeric(1))

```
```r solution
cv <- vapply(fields, function(v) sd(v) / mean(v), numeric(1))
```
@hint Третій аргумент `vapply` — зразок результату: `numeric(1)`.
@check vars=cv uses=vapply

## Завдання: Фільтр полів
Залиште у списку `good` лише ті поля, середня урожайність яких більша за 5.5 (функція `Filter`).
```r setup
fields <- list(A = c(5.1, 5.4, 4.9, 5.8), B = c(6.3, 6.8, 6.1, 7.0), C = c(5.7, 5.5, 6.0))
```
```r starter
# good <- Filter(...)

```
```r solution
good <- Filter(function(v) mean(v) > 5.5, fields)
```
@hint Перший аргумент `Filter` — функція-предикат, що повертає `TRUE`/`FALSE`.
@check vars=good uses=Filter

## Завдання: Накопичення через Reduce
Виведіть накопичені добутки чисел 1…6 (`1 2 6 24 120 720`) за допомогою `Reduce` з `accumulate = TRUE`.
```r starter
# Reduce(...)

```
```r solution
Reduce(`*`, 1:6, accumulate = TRUE)
```
@hint Функцію множення можна передати в зворотних лапках: `` `*` ``.
@check output uses=Reduce

## Завдання: Матриця з векторів
Список `rows` містить три вектори однакової довжини. Складіть із них матрицю `M` (кожен вектор — рядок) за допомогою `do.call()` та `rbind`.
```r setup
rows <- list(c(1, 2, 3), c(4, 5, 6), c(7, 8, 9))
```
```r starter
# M <- do.call(...)

```
```r solution
M <- do.call(rbind, rows)
```
@hint `do.call(rbind, rows)`.
@check vars=M uses=do.call
