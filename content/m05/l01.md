# Умовні вирази
> Програма приймає рішення: if, else, switch.

Оператор `if` виконує код, лише якщо умова істинна. Умова має бути **одним** значенням `TRUE`/`FALSE`:

```r
ph <- 5.8
if (ph < 6.5) {
  print("ґрунт кислий")
} else if (ph <= 7.5) {
  print("ґрунт нейтральний")
} else {
  print("ґрунт лужний")
}
```

`if` теж повертає значення, тому результат можна присвоїти змінній:

```r
verdict <- if (ph < 6.5) "кислий" else "некислий"
verdict
```

> ⚠️ Для умов у `if` використовують **`&&`** та **`||`** (працюють з одним значенням, обчислюють лінивo). Оператори `&` та `|` призначені для векторів.

```r
temp <- 22
if (temp > 15 && temp < 30) print("комфортно")
c(TRUE, FALSE) & c(TRUE, TRUE)    # поелементно
```

### switch — вибір за значенням

```r
crop <- "соя"
n_dose <- switch(crop,
  "пшениця" = 120,
  "кукурудза" = 150,
  "соя" = 30,
  0                       # значення за замовчуванням
)
n_dose
```

### Захист від помилок

```r
x <- -4
if (x < 0) {
  message("Від'ємне число — корінь не існує")
} else {
  sqrt(x)
}
# stopifnot зупиняє виконання, якщо умова хибна
stopifnot(is.numeric(x))
```

`tryCatch()` дозволяє перехопити помилку чи попередження й повернути запасне значення:

```r
tryCatch(as.numeric("abc"), warning = function(w) NA)
tryCatch(log(-1), warning = function(w) "не визначено")
```

## Завдання: Норма азоту

```r setup

```

## Завдання: Перевірка вхідних даних
Напишіть код, який зупиняє виконання з помилкою (`stopifnot`), якщо `yield` містить від'ємні значення, а інакше виводить середнє. Для поточних даних має вивестися середнє.
```r setup
yield <- c(5.2, 6.1, 5.8)
```
```r starter
# stopifnot(...)
# mean(yield)

```
```r solution
stopifnot(all(yield >= 0))
mean(yield)
```
@hint Усі елементи мають бути невід'ємні: `all(yield >= 0)`.
@check output uses=stopifnot

## Тест: Оператори && та &
Що відрізняє `&&` від `&`?
- [ ] нічого, це синоніми
- [x] `&&` працює з одиночними значеннями й зупиняється, коли відповідь відома; `&` — векторизований
- [ ] `&&` швидше працює з матрицями
- [ ] `&` можна використовувати лише в `if`
@explain У `if (...)` потрібна одна умова, тому використовують `&&`/`||`. Для порівнянь над векторами — `&`/`|`.
