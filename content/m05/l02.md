# Цикли
> for, while, repeat — повторення дій.

### Цикл for

Виконує блок для кожного елемента послідовності:

```r
for (i in 1:5) {
  print(i^2)
}
```

Накопичення результату:

```r
total <- 0
for (x in c(4, 8, 15)) total <- total + x
total
```

Якщо результат — вектор, заздалегідь створіть його потрібного розміру (це набагато швидше, ніж нарощувати):

```r
squares <- numeric(10)         # вектор із десяти нулів
for (i in 1:10) squares[i] <- i^2
squares
```

> 💡 Для обходу за індексами краще писати `seq_along(x)`, а не `1:length(x)`: якщо вектор порожній, `1:length(x)` дасть `1, 0`, а `seq_along(x)` — нічого.

### Цикл while

Працює, поки умова істинна. Приклад: за скільки років вклад із 5 % річних подвоїться?

```r
sum_now <- 1000
years <- 0
while (sum_now < 2000) {
  sum_now <- sum_now * 1.05
  years <- years + 1
}
years
```

### break та next

`next` пропускає поточну ітерацію, `break` виходить із циклу:

```r
x <- c(12, 8, NA, 15, 20, 9)
total <- 0
for (v in x) {
  if (is.na(v)) next          # пропускаємо пропуски
  total <- total + v
  if (total > 30) break       # достатньо
}
total
```

### repeat

Нескінченний цикл, який зупиняють `break`:

```r
n <- 0
repeat {
  n <- n + 1
  if (n^2 > 50) break
}
n
```

> 💡 У R багато операцій векторизовані (`sum(1:10)`, `cumsum`, `x^2`) — вони коротші й швидші за цикл. Цикли потрібні, коли наступний крок залежить від попереднього (моделі зростання, ітераційні методи).

## Завдання: Зростання популяції
Популяція `N` починається з 100 особин і щороку зростає на 5 %. Скільки повних років пройде, поки чисельність досягне 200 або більше? Результат — змінна `years` (цикл `while`).
```r starter
# N <- 100
# years <- 0
# while (...) { ... }

```
```r solution
N <- 100
years <- 0
while (N < 200) {
  N <- N * 1.05
  years <- years + 1
}
```
@hint Умова продовження — `N < 200`.
@hint Усередині: `N <- N * 1.05; years <- years + 1`.
@check vars=years uses=while

## Завдання: Пропуски й зупинка
Рухайтеся по `x`: пропускайте `NA` (`next`), додавайте значення до `total`, лічіть їх у `n_used`, і зупиніться (`break`), щойно `total` перевищить 30.
```r setup
x <- c(12, 8, NA, 15, 20, 9)
```
```r starter
# total <- 0
# n_used <- 0
# for (v in x) { ... }

```
```r solution
total <- 0
n_used <- 0
for (v in x) {
  if (is.na(v)) next
  total <- total + v
  n_used <- n_used + 1
  if (total > 30) break
}
```
@hint Спершу `if (is.na(v)) next`, далі додавання, потім перевірка на `break`.
@check vars=total,n_used uses=next,break

## Завдання: Числа Фібоначчі
Створіть вектор `fib` із перших 15 чисел Фібоначчі (1, 1, 2, 3, 5, …) у циклі: кожне наступне — сума двох попередніх.
```r starter
# fib <- numeric(15)
# fib[1] <- 1; fib[2] <- 1
# for (...) ...

```
```r solution
fib <- numeric(15)
fib[1] <- 1
fib[2] <- 1
for (i in 3:15) fib[i] <- fib[i - 1] + fib[i - 2]
```
@hint Цикл починається з `i = 3`.
@check vars=fib

## Завдання: Гіпотеза Коллатца
Для `n <- 27` підрахуйте, скільки кроків потрібно, щоб дійти до 1: якщо `n` парне — ділимо на 2, інакше — `3n + 1`. Кількість кроків — `steps` (цикл `while`).
```r starter
# n <- 27
# steps <- 0
# while (n != 1) { ... }

```
```r solution
n <- 27
steps <- 0
while (n != 1) {
  n <- if (n %% 2 == 0) n / 2 else 3 * n + 1
  steps <- steps + 1
}
```
@hint Парність перевіряє `n %% 2 == 0`.
@check vars=steps uses=while

## Тест: seq_along

- [ ] він швидший у 100 разів
- [x] для порожнього вектора він не створює індексів, а `1:length(x)` дає `1, 0`
- [ ] він повертає дробові індекси
- [ ] різниці немає
