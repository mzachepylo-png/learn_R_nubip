# Власні функції
> Загорніть повторюваний код у функцію — і користуйтеся нею як вбудованою.

Функція створюється ключовим словом `function`. Остання обчислена величина автоматично стає результатом (явний `return()` необов'язковий):

```r
celsius_to_f <- function(c) {
  c * 9 / 5 + 32
}
celsius_to_f(100)
celsius_to_f(c(0, 37, 100))   # векторизація «безкоштовно»
```

### Аргументи за замовчуванням

```r
compound <- function(P, years, r = 0.05) {
  P * (1 + r)^years
}
compound(1000, 10)            # r = 0.05
compound(1000, 10, r = 0.08)  # перевизначаємо
compound(P = 500, r = 0.1, years = 3)
```

### Кілька значень на виході

Поверніть список:

```r
describe <- function(x) {
  list(n = length(x), mean = mean(x), sd = sd(x))
}
res <- describe(c(5.1, 6.0, 5.6, 6.4))
res$mean
```

### Область видимості

Змінні всередині функції — локальні й зникають після виходу. Зовнішні змінні функція бачить, але не змінює:

```r
x <- 10
f <- function() {
  x <- 99     # локальна копія
  x
}
f()
x             # глобальна не змінилась
```

### Перевірка аргументів

```r
safe_mean <- function(x) {
  stopifnot(is.numeric(x))
  mean(x, na.rm = TRUE)
}
safe_mean(c(1, NA, 3))
```

### Анонімні функції

Для коротких одноразових функцій є запис `\(x)`:

```r
sapply(1:5, \(i) i^2)
sapply(c(1, 4, 9), function(v) sqrt(v))
```

> 💡 Дотримуйтесь правила «одна функція — одна задача» і давайте їй промовисте ім'я.

## Завдання: Градуси Фаренгейта
Напишіть функцію `celsius_to_f(c)`, що переводить температуру з °C у °F за формулою `c * 9 / 5 + 32`.
```r starter
# celsius_to_f <- function(c) {
#
# }

```
```r solution
celsius_to_f <- function(c) {
  c * 9 / 5 + 32
}
```
@hint Тіло функції — одна формула; `return` не обов'язковий.
@check uses=function
@test is.function(celsius_to_f) && isTRUE(all.equal(celsius_to_f(c(0, 37, 100)), c(32, 98.6, 212))) => Функція має повертати 32, 98.6 і 212 для 0, 37 і 100 °C.

## Завдання: Складний відсоток
Напишіть функцію `compound(P, years, r = 0.05)`, що повертає суму вкладу `P` через `years` років при ставці `r`.
```r starter
# compound <- function(P, years, r = 0.05) {
#
# }

```
```r solution
compound <- function(P, years, r = 0.05) {
  P * (1 + r)^years
}
```
@hint Формула: `P * (1 + r)^years`.
@check uses=function
@test is.function(compound) && isTRUE(all.equal(compound(1000, 2), 1102.5)) => compound(1000, 2) має дорівнювати 1102.5 (ставка за замовчуванням 5 %).
@test is.function(compound) && isTRUE(all.equal(compound(1000, 2, r = 0.1), 1210)) => compound(1000, 2, r = 0.1) має дорівнювати 1210.

## Завдання: Описова статистика
Напишіть функцію `describe(x)`, що повертає **список** із елементами `n` (кількість), `mean` (середнє) та `sd` (стандартне відхилення).
```r starter
# describe <- function(x) {
#
# }

```
```r solution
describe <- function(x) {
  list(n = length(x), mean = mean(x), sd = sd(x))
}
```
@hint Повертайте `list(n = ..., mean = ..., sd = ...)`.
@check uses=function
@test is.function(describe) && is.list(describe(c(1, 2, 3))) && identical(names(describe(1:3)), c("n", "mean", "sd")) => Список має містити елементи n, mean, sd (саме в такому порядку).
@test is.function(describe) && isTRUE(all.equal(describe(c(2, 4, 9))$mean, 5)) => Перевірте обчислення середнього.

## Завдання: Стандартна похибка
Напишіть функцію `se(x)` — стандартна похибка середнього: `sd(x) / sqrt(length(x))`. Функція має ігнорувати пропущені значення (`NA`).
```r starter
# se <- function(x) {
#
# }

```
```r solution
se <- function(x) {
  x <- x[!is.na(x)]
  sd(x) / sqrt(length(x))
}
```
@hint Спочатку відкиньте `NA`: `x <- x[!is.na(x)]`.
@check uses=function
@test is.function(se) && isTRUE(all.equal(se(c(2, 4, 6, 8)), sd(c(2, 4, 6, 8)) / 2)) => se(c(2, 4, 6, 8)) має дорівнювати sd/2.
@test is.function(se) && isTRUE(all.equal(se(c(2, 4, NA, 6, 8)), sd(c(2, 4, 6, 8)) / 2)) => Функція має ігнорувати NA.

## Завдання: Анонімна функція
Використайте `sapply` з анонімною функцією `\(i)`, щоб отримати вектор `sq` квадратів чисел від 1 до 6.

```r starter
# sq <- sapply(...)

```

@check vars=sq uses=sapply

## Тест: Область видимості
Що виведе код?
```r static
x <- 10
f <- function() { x <- 99; x }
f()
x
```
- [ ] `99` та `99`
- [x] `99` та `10`
- [ ] `10` та `99`
- [ ] `10` та `10`
@explain Присвоєння `x <- 99` всередині функції створює *локальну* змінну. Глобальна `x` лишається 10.
