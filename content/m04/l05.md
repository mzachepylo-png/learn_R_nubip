# Групові обчислення
> Порахуйте середнє, суму чи частку окремо для кожної групи.

Типове завдання аналізу даних: «середня урожайність за варіантами досліду», «кількість за категоріями». У R для цього є кілька інструментів.

### tapply

`tapply(вектор, групи, функція)` повертає результат для кожної групи:

```r
tapply(iris$Sepal.Length, iris$Species, mean)
tapply(mtcars$mpg, mtcars$cyl, max)
```

### aggregate

`aggregate()` працює з формулою `змінна ~ групи` та повертає дата-фрейм:

```r
aggregate(mpg ~ cyl, data = mtcars, FUN = mean)
aggregate(len ~ supp + dose, data = ToothGrowth, FUN = mean)   # дві групувальні змінні
aggregate(cbind(mpg, hp) ~ cyl, data = mtcars, FUN = median)   # кілька змінних
```

### table: частоти та двовимірні таблиці

```r
table(mtcars$cyl)
table(mtcars$cyl, mtcars$gear)                      # перехресна таблиця
t2 <- table(cyl = mtcars$cyl, gear = mtcars$gear)   # з назвами осей
prop.table(t2, margin = 1)                          # частки по рядках
```

### split + sapply

`split()` ділить вектор або таблицю на групи, а `sapply` обчислює показник у кожній:

```r
groups <- split(ToothGrowth$len, ToothGrowth$supp)
names(groups)
sapply(groups, median)
sapply(groups, function(g) c(середнє = mean(g), sd = sd(g)))
```

> 💡 Для більш складних зведень знадобляться пакети (`dplyr`), але `tapply`, `aggregate` та `table` закривають більшість потреб у базовому R.

## Завдання: Середнє за видами
Обчисліть середню довжину чашолистка `Sepal.Length` для кожного виду `Species` набору `iris` функцією `tapply()`. Збережіть у `means`.
```r starter
# means <- tapply(...)

```
```r solution
means <- tapply(iris$Sepal.Length, iris$Species, mean)
```
@hint `tapply(значення, групи, функція)`.
@check vars=means uses=tapply

## Завдання: Aggregate
Використайте `aggregate()` та формулу, щоб порахувати середній `mpg` за кількістю циліндрів `cyl` у `mtcars`. Збережіть у `agg`.
```r starter
# agg <- aggregate(...)

```
```r solution
agg <- aggregate(mpg ~ cyl, data = mtcars, FUN = mean)
```
@hint Формула: `mpg ~ cyl`, дані — `data = mtcars`.
@check vars=agg uses=aggregate

## Завдання: Медіана за групами
Для набору `ToothGrowth` обчисліть медіану довжини зуба `len` окремо для кожного способу введення `supp`, використавши `split()` та `sapply()`. Результат — `med`.
```r starter
# groups <- split(...)
# med <- sapply(...)

```
```r solution

med <- sapply(groups, median)
```
@hint `split(ToothGrowth$len, ToothGrowth$supp)` дає список векторів.
@check vars=med uses=split,sapply

## Завдання: Дві групувальні змінні
Порахуйте середню `len` у `ToothGrowth` за комбінаціями `supp` і `dose`. Збережіть у `agg2`.

```r starter
# agg2 <- aggregate(...)

```

## Тест: Формула aggregate
Що означає запис `aggregate(y ~ g, data = d, FUN = sum)`?
- [ ] суму `g` для кожного значення `y`
- [x] суму `y` для кожного значення `g`
- [ ] суму всіх стовпців таблиці `d`
- [ ] кореляцію між `y` та `g`
@explain Ліворуч від `~` — змінна, яку підсумовуємо, праворуч — групувальна змінна.
