# Фактори та категорії
> Фактор — спосіб зберігати категоріальні змінні: сорт, тип ґрунту, рівень дози.

Категоріальні дані мають обмежений набір значень — **рівнів** (*levels*). У R для них є тип `factor`:

```r
soil <- c("глинистий", "піщаний", "суглинок", "піщаний", "суглинок", "піщаний")
f <- factor(soil)
f
levels(f)
nlevels(f)
table(f)          # частоти
as.integer(f)     # внутрішні коди рівнів
```

### Порядок рівнів

За замовчуванням рівні сортуються за алфавітом. Для порядкових даних задайте порядок самі:

```r
dose <- c("низька", "висока", "середня", "низька", "висока")
dose_f <- factor(dose, levels = c("низька", "середня", "висока"), ordered = TRUE)
dose_f
dose_f < "висока"   # порівняння доступні лише для впорядкованих
table(dose_f)
```

### Частки

```r
tab <- table(f)
prop.table(tab)           # частки
round(prop.table(tab), 2)
```

### Розбиття числових даних на інтервали

`cut()` перетворює число на категорію:

```r
yield <- c(4.2, 5.8, 6.9, 7.5, 5.1, 6.4)
cut(yield, breaks = c(0, 5, 6.5, Inf), labels = c("низька", "середня", "висока"))
cut(yield, breaks = 3)   # три рівні інтервали
```

### Базовий рівень

Перший рівень фактора використовується як «еталонний» у моделях. Змінити його можна через `relevel()`:

```r
treat <- factor(c("добриво", "контроль", "добриво", "контроль"))
levels(treat)
relevel(treat, ref = "контроль")
```

## Завдання: Впорядкований фактор
Створіть впорядкований фактор `dose_f` з вектора `dose` з рівнями у порядку `"низька"` < `"середня"` < `"висока"`.
```r setup
dose <- c("низька", "висока", "середня", "низька", "висока")
```
```r starter
# dose_f <- factor(...)

```
```r solution
dose_f <- factor(dose, levels = c("низька", "середня", "висока"), ordered = TRUE)
```
@hint Порядок задається аргументом `levels`, а впорядкованість — `ordered = TRUE`.
@check vars=dose_f

## Завдання: Категорії врожайності
Створіть фактор `cls`, розбивши `yield` на три категорії: до 5 включно — `"низька"`, від 5 до 6.5 включно — `"середня"`, вище — `"висока"`. Використайте `cut()`.
```r setup
yield <- c(4.2, 5.8, 6.9, 7.5, 5.1, 6.4, 5.0, 6.5)
```
```r starter
# cls <- cut(...)

```
```r solution
cls <- cut(yield, breaks = c(0, 5, 6.5, Inf), labels = c("низька", "середня", "висока"))
```
@hint Межі інтервалів: `c(0, 5, 6.5, Inf)`; за замовчуванням інтервали закриті справа: (0,5], (5,6.5], (6.5,Inf].
@check vars=cls uses=cut

## Завдання: Частки у відсотках
Обчисліть частку кожного типу ґрунту (функції `table` і `prop.table`), округліть до 2 знаків і виведіть.
```r setup
soil <- c("глинистий", "піщаний", "суглинок", "піщаний", "суглинок", "піщаний")
```
```r starter
# round(prop.table(...), 2)

```
```r solution
round(prop.table(table(soil)), 2)
```
@hint `prop.table(table(soil))` дає частки.
@check output uses=prop.table

## Завдання: Контрольний рівень
Змініть фактор `treat` так, щоб базовим (першим) рівнем став `"контроль"`. Результат запишіть у `treat2`.
```r setup
treat <- factor(c("добриво", "контроль", "добриво", "контроль", "добриво"))
```
```r starter
# treat2 <- relevel(...)

```
```r solution

```
@hint `relevel(фактор, ref = "...")`.
@check vars=treat2 uses=relevel

## Тест: Коди рівнів
Що виведе `as.integer(factor(c("10", "20", "10")))`?
- [ ] `10 20 10`
- [x] `1 2 1`
- [ ] `"10" "20" "10"`
- [ ] `1 2 3`
@explain `as.integer` повертає внутрішні коди рівнів (1 — перший рівень «10», 2 — «20»), а не самі значення. Щоб отримати числа, спершу перетворіть на текст: `as.numeric(as.character(f))`.
