# Фільтрація, сортування та об'єднання
> Відберіть потрібні рядки, упорядкуйте їх та зведіть кілька таблиць разом.

```r
trial <- data.frame(
  plot  = 1:8,
  treat = rep(c("A", "B"), each = 4),
  yield = c(5.1, 5.4, 4.9, 5.8, 6.3, 6.8, 6.1, 7.0)
)
```

### Фільтрація рядків

```r
trial[trial$treat == "B" & trial$yield > 6.5, ]
subset(trial, treat == "B" & yield > 6.5)             # зручніший запис
subset(trial, yield > 6, select = c(plot, yield))     # ще й обрати стовпці
```

### Сортування

`order()` повертає індекси, які впорядковують вектор:

```r
trial[order(trial$yield), ]                  # за зростанням
trial[order(-trial$yield), ]                 # за спаданням
trial[order(trial$treat, -trial$yield), ]    # спершу за treat, потім за yield (спадно)
```

### Нові та перетворені стовпці

```r
trial <- transform(trial, yield_kg = yield * 1000, high = yield > 6)
head(trial, 3)
```

### Додавання рядків та стовпців

```r
new_row <- data.frame(plot = 9, treat = "B", yield = 6.6, yield_kg = 6600, high = TRUE)
trial2 <- rbind(trial, new_row)
nrow(trial2)
cbind(trial[, 1:2], z = scale(trial$yield)[, 1])
```

### Об'єднання таблиць за ключем

```r
soil <- data.frame(plot = c(1, 2, 3, 4, 9), ph = c(6.1, 6.4, 5.8, 7.0, 6.6))
merge(trial, soil, by = "plot")                # лише збіги
merge(trial, soil, by = "plot", all.x = TRUE)  # усі рядки trial (як LEFT JOIN)
```

### Унікальні значення та дублікати

```r
unique(trial$treat)
duplicated(c(1, 2, 2, 3, 1))
```

## Завдання: Відбір рядків
У `trial` залиште у змінній `high_B` рядки, де варіант `treat` дорівнює `"B"`, а `yield` більша за 6.5.
```r setup
trial <- data.frame(plot = 1:8, treat = rep(c("A", "B"), each = 4), yield = c(5.1, 5.4, 4.9, 5.8, 6.3, 6.8, 6.1, 7.0))
```
```r starter
# high_B <- subset(...)

```
```r solution
high_B <- subset(trial, treat == "B" & yield > 6.5)
```
@hint Умови з'єднуються оператором `&`.
@check vars=high_B

## Завдання: Сортування за спаданням
Створіть `sorted` — дата-фрейм `trial`, упорядкований за зменшенням `yield`.
```r setup
trial <- data.frame(plot = 1:8, treat = rep(c("A", "B"), each = 4), yield = c(5.1, 5.4, 4.9, 5.8, 6.3, 6.8, 6.1, 7.0))
```
```r starter
# sorted <- trial[order(...), ]

```
```r solution
sorted <- trial[order(-trial$yield), ]
```
@hint Мінус перед числовим вектором змінює порядок на зворотний: `order(-trial$yield)`.
@check vars=sorted

## Завдання: Вибір стовпців
Створіть `slim` — таблицю лише зі стовпцями `plot` та `yield`.
```r setup
trial <- data.frame(plot = 1:8, treat = rep(c("A", "B"), each = 4), yield = c(5.1, 5.4, 4.9, 5.8, 6.3, 6.8, 6.1, 7.0))
```
```r starter
# slim <- trial[, ...]

```
```r solution
slim <- trial[, c("plot", "yield")]
```
@hint Назви стовпців передайте вектором.
@check vars=slim

## Завдання: Об'єднання
До таблиці `trial` додайте властивості ґрунту з таблиці `soil` за ключем `plot` (залиште **всі** рядки `trial`). Результат — `full`.
```r setup
trial <- data.frame(plot = 1:6, yield = c(5.1, 5.4, 4.9, 5.8, 6.3, 6.8))
soil <- data.frame(plot = c(1, 2, 3, 4, 7), ph = c(6.1, 6.4, 5.8, 7.0, 6.6))
```
```r starter
# full <- merge(...)

```
```r solution
full <- merge(trial, soil, by = "plot", all.x = TRUE)
```
@hint За замовчуванням `merge` залишає лише рядки зі збігом ключів.
@hint Додайте аргумент `all.x = TRUE`.
@check vars=full

## Завдання: Нові поля
За допомогою `transform()` додайте до `trial` стовпці `yield_kg` (`yield * 1000`) і логічний `high` (`yield > 6`). Результат збережіть у `trial2`.
```r setup
trial <- data.frame(plot = 1:6, yield = c(5.1, 5.4, 4.9, 6.3, 6.8, 6.1))
```
```r starter
# trial2 <- transform(trial, ...)

```
```r solution
trial2 <- transform(trial, yield_kg = yield * 1000, high = yield > 6)
```
@hint Нові стовпці задаються як `назва = вираз` прямо в `transform`.
@check vars=trial2 uses=transform

## Тест: Результат merge
Таблиці `a` і `b` мають спільний стовпець `id`. Яким буде результат `merge(a, b, by = "id")` за замовчуванням?
- [ ] усі рядки обох таблиць
- [x] лише рядки, ключ `id` яких є в обох таблицях
- [ ] усі рядки таблиці `a`
- [ ] помилка, якщо розміри таблиць різні
@explain За замовчуванням виконується «внутрішнє» з'єднання (*inner join*). Аргументи `all.x`, `all.y`, `all` дозволяють залишати й нез'єднані рядки.
