# Списки
> Список зберігає елементи різних типів і довжин в одній структурі.

Якщо вектор — це «однорідна коробка», то **список** (`list`) — шафа з відділеннями: у ньому можуть лежати числа, тексти, вектори, інші списки й навіть функції.

```r
field <- list(
  name = "Північне",
  area = 45.5,
  crops = c("пшениця", "соя"),
  irrigated = TRUE
)
field
str(field)       # компактна структура
length(field)
names(field)
```

### Доступ до елементів

| Запис | Що повертає |
|---|---|
| `field$area` | сам елемент `area` |
| `field[["area"]]` | те саме (за ім'ям або номером) |
| `field[2]` | **підсписок** довжини 1 |

```r
field$crops[2]            # другий елемент вектора crops
field[["name"]]
class(field[1])           # "list"
class(field[[1]])         # "character"
```

> ⚠️ Подвійні дужки `[[ ]]` дістають *вміст*, а одинарні `[ ]` повертають *список* меншого розміру.

### Зміна списку

```r
field$owner <- "ФГ Колос"     # додати
field$area <- 50              # змінити
field$irrigated <- NULL       # видалити
names(field)
```

### Робота зі списками

```r
data <- list(a = c(1, 2, 3), b = c(4, 5), c = 1:10)
sapply(data, length)    # застосувати функцію до кожного елемента
sapply(data, mean)
lapply(data, range)     # результат — знову список
unlist(data)            # «розплющити» в один вектор
```

## Завдання: Довжини елементів
Для списку `data` створіть вектор `lens` — довжини кожного елемента та `means` — середнє кожного елемента (функція `sapply`).
```r setup
data <- list(a = c(1, 2, 3), b = c(4, 5), c = 1:10)
```
```r starter
# lens <- sapply(...)
# means <- sapply(...)

```
```r solution
lens <- sapply(data, length)
means <- sapply(data, mean)
```
@hint `sapply(список, функція)` застосовує функцію до кожного елемента.
@check vars=lens,means uses=sapply

## Завдання: Розплющити список
Перетворіть список `parts` на єдиний числовий вектор `all_values` (функція `unlist`) й обчисліть його суму в змінну `total`.
```r setup
parts <- list(c(1.5, 2.5), c(3, 4, 5), 10)
```
```r starter
# all_values <- unlist(...)
# total <- ...

```
```r solution
all_values <- unlist(parts)
total <- sum(all_values)
```
@hint `unlist()` об'єднує всі елементи списку в один вектор.
@check vars=all_values,total
