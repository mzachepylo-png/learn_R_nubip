# Дата-фрейми
> Таблиця даних: рядки — спостереження, стовпці — змінні.

**Дата-фрейм** (`data.frame`) — головний формат для аналізу даних. Це список однакових за довжиною стовпців, кожен із яких має свій тип.

```r
trial <- data.frame(
  plot = 1:6,
  treat = rep(c("контроль", "добриво"), each = 3),
  yield = c(5.1, 5.4, 4.9, 6.3, 6.8, 6.1)
)
trial
```

### Огляд структури

```r
str(trial)        # типи стовпців
summary(trial)    # зведення по кожному стовпцю
dim(trial)        # рядки і стовпці
nrow(trial); ncol(trial)
names(trial)
head(trial, 3)    # перші рядки
tail(trial, 2)    # останні
```

### Доступ до даних

```r
trial$yield              # стовпець (вектор)
trial[["treat"]]         # те саме
trial[2, ]               # другий рядок
trial[, c("plot", "yield")]
trial[2, "yield"]        # окрема клітинка
trial[trial$yield > 6, ] # рядки за умовою
```

### Нові стовпці

```r
trial$yield_kg <- trial$yield * 1000
trial$high <- trial$yield > 6
trial
```

### Вбудовані набори даних

У R є десятки навчальних наборів: `mtcars` (автомобілі), `iris` (ірисів), `airquality` (повітря), `ToothGrowth` (ріст зубів), `women`, `cars` та інші.


## Завдання: Власний дата-фрейм
Створіть дата-фрейм `trial` із трьома стовпцями: `plot` — числа 1–6, `treat` — `"контроль"` (3 рази) і `"добриво"` (3 рази) в такому порядку, `yield` — `5.1, 5.4, 4.9, 6.3, 6.8, 6.1`.
```r starter
# trial <- data.frame(...)

```
```r solution
trial <- data.frame(
  plot = 1:6,

  yield = c(5.1, 5.4, 4.9, 6.3, 6.8, 6.1)

```
@hint `data.frame(стовпець1 = ..., стовпець2 = ...)`.
@hint Для `treat` зручно скористатися `rep(..., each = 3)`.
@check vars=trial

## Завдання: Новий стовпець
До дата-фрейму `trial` додайте стовпець `yield_kg` — урожайність у кілограмах на гектар (у `yield` дані в т/га, тому множте на 1000).
```r setup
trial <- data.frame(plot = 1:6, treat = rep(c("контроль", "добриво"), each = 3), yield = c(5.1, 5.4, 4.9, 6.3, 6.8, 6.1))
```
```r starter
# trial$yield_kg <- ...

```
```r solution
trial$yield_kg <- trial$yield * 1000
```
@hint Новий стовпець створюється присвоєнням: `trial$нова_назва <- вираз`.
@check vars=trial
