# Закон великих чисел, ЦГТ і bootstrap
> Чому середнє стабілізується, а вибіркові середні нормальні.

### Закон великих чисел

Зі зростанням кількості спостережень вибіркове середнє наближається до теоретичного:

```r
set.seed(1)
flips <- rbinom(1000, 1, 0.5)
run_mean <- cumsum(flips) / seq_along(flips)
plot(run_mean, type = "l", ylim = c(0, 1), xlab = "n", ylab = "частка орлів")
abline(h = 0.5, col = "red", lty = 2)
```

### Центральна гранична теорема

Навіть якщо дані **не** нормальні, розподіл вибіркових середніх при великому розмірі вибірки наближається до нормального зі стандартною похибкою `σ/√n`:

```r
set.seed(2)
means <- replicate(2000, mean(rexp(30, rate = 1)))   # середні вибірок з 30 значень
hist(means, breaks = 30, freq = FALSE, col = "grey90", main = "Розподіл вибіркових середніх")
curve(dnorm(x, 1, 1 / sqrt(30)), add = TRUE, col = "red", lwd = 2)
c(емпірична = sd(means), теоретична = 1 / sqrt(30))
```

### Стандартна похибка середнього

```r
x <- c(5.1, 5.4, 4.9, 5.8, 6.2, 5.5, 5.3)
se <- sd(x) / sqrt(length(x))
se
mean(x) + c(-1, 1) * qt(0.975, df = length(x) - 1) * se    # 95 % довірчий інтервал
```

### Bootstrap

Bootstrap оцінює невизначеність, багаторазово перевибираючи **з повторенням** наявну вибірку:

```r
set.seed(3)
boot <- replicate(5000, mean(sample(x, replace = TRUE)))
quantile(boot, c(0.025, 0.975))     # перцентильний 95 % інтервал
sd(boot)                            # bootstrap-оцінка стандартної похибки
```

### Перестановочний тест

Чи справжня різниця середніх двох груп? Перемішуємо мітки груп багато разів і дивимося, як часто випадкова різниця не менша за спостережену:

```r
a <- c(5.1, 5.4, 4.9, 5.8)
b <- c(6.3, 6.8, 6.1, 7.0)
obs <- mean(b) - mean(a)
all_v <- c(a, b)
set.seed(4)
perm <- replicate(5000, {
  idx <- sample(length(all_v), length(a))
  mean(all_v[-idx]) - mean(all_v[idx])
})
mean(abs(perm) >= abs(obs))         # емпіричне p-значення
```

## Завдання: Стандартна похибка за ЦГТ
Згенеруйте 2000 вибіркових середніх, кожне з вибірки з 30 значень `rexp(30, 1)` (`set.seed(2)`), і збережіть їх у `means`. У змінну `se_emp` запишіть їх стандартне відхилення.
```r starter
# set.seed(2)
# means <- replicate(...)
# se_emp <- ...

```
```r solution
set.seed(2)
means <- replicate(2000, mean(rexp(30, rate = 1)))
se_emp <- sd(means)
```
@hint Усередині `replicate` — `mean(rexp(30, rate = 1))`.
@check uses=replicate
@test length(means) == 2000 && abs(se_emp - 1 / sqrt(30)) < 0.015 => Емпірична стандартна похибка має бути ≈ 1/√30 ≈ 0.183.

## Завдання: Bootstrap
Виконайте bootstrap середнього для `x` (`set.seed(3)`, 5000 повторів, `sample(x, replace = TRUE)`) і збережіть 95 % перцентильний інтервал у `ci_boot`.
```r setup
x <- c(5.1, 5.4, 4.9, 5.8, 6.2, 5.5, 5.3)
```
```r starter
# set.seed(3)
# boot <- replicate(...)
# ci_boot <- quantile(...)

```
```r solution
set.seed(3)
boot <- replicate(5000, mean(sample(x, replace = TRUE)))
ci_boot <- quantile(boot, c(0.025, 0.975))
```
@hint Нижня й верхня межі — квантилі 0.025 та 0.975.
@check uses=replicate,sample,quantile
@test length(ci_boot) == 2 && abs(ci_boot[[1]] - .sol$ci_boot[[1]]) < 0.1 && abs(ci_boot[[2]] - .sol$ci_boot[[2]]) < 0.1 => Інтервал має бути близьким до очікуваного (приблизно 5.1–5.8).

## Завдання: Перестановочний тест
Обчисліть емпіричне p-значення перестановочного тесту для різниці середніх груп `a` та `b` (5000 перестановок, `set.seed(4)`): `p_perm = частка |перестановочна різниця| ≥ |спостережена|`.
```r setup
a <- c(5.1, 5.4, 4.9, 5.8)
b <- c(6.3, 6.8, 6.1, 7.0)
```
```r starter
# obs <- ...
# all_v <- c(a, b)
# set.seed(4)
# perm <- replicate(...)
# p_perm <- ...

```
```r solution
obs <- mean(b) - mean(a)
all_v <- c(a, b)
set.seed(4)
perm <- replicate(5000, {
  idx <- sample(length(all_v), length(a))
  mean(all_v[-idx]) - mean(all_v[idx])
})
p_perm <- mean(abs(perm) >= abs(obs))
```
@hint У кожній перестановці випадково вибирайте `length(a)` значень як «групу a».
@check uses=replicate
@test exists("p_perm") && abs(p_perm - .sol$p_perm) < 0.03 => p_perm має бути близьким до очікуваного (дуже мале значення).
