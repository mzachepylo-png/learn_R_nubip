# Випадковість і вибірки
> Генеруйте випадкові числа, вибирайте з сукупності та повторюйте експерименти.

Комп'ютер генерує **псевдовипадкові** числа за алгоритмом. Щоб результат можна було відтворити, фіксують початкове значення — «зерно»:

```r
set.seed(123)
runif(3)       # рівномірні на [0, 1]
set.seed(123)
runif(3)       # ті самі числа
```

### sample — вибірка

```r
set.seed(1)
sample(1:6, 1)                         # кидок кубика
sample(1:6, 10, replace = TRUE)        # 10 кидків (з поверненням)
sample(c("орел", "решка"), 5, replace = TRUE)
sample(1:10)                           # випадкова перестановка
sample(c("A", "B", "C"), 1000, replace = TRUE, prob = c(0.5, 0.3, 0.2))
```

Вибірка рядків таблиці — через індекси:

```r
set.seed(10)
idx <- sample(nrow(iris), 5)
iris[idx, ]
```

### Випадкові числа з розподілів

```r
set.seed(2024)
x <- rnorm(1000, mean = 50, sd = 10)    # нормальний
c(mean(x), sd(x))
rbinom(5, size = 10, prob = 0.3)        # біноміальний
rpois(5, lambda = 4)                    # Пуассона
rexp(3, rate = 0.5)                     # експоненціальний
```

### replicate — повторити експеримент багато разів

```r
set.seed(42)
sums <- replicate(10000, sum(sample(1:6, 2, replace = TRUE)))   # сума двох кубиків
table(sums)
mean(sums == 7)         # частка сум, що дорівнюють 7 (теоретично 1/6)
```

> 💡 Частота події в довгій серії дослідів наближається до її ймовірності — це основа методу Монте-Карло.

## Завдання: Десять кидків
Зафіксуйте зерно `set.seed(1)` і імітуйте 10 кидків кубика (з поверненням) — вектор `dice`.
```r starter
# set.seed(1)
# dice <- ...

```
```r solution
set.seed(1)
dice <- sample(1:6, 10, replace = TRUE)
```
@hint `sample(1:6, 10, replace = TRUE)`.
@check vars=dice uses=set.seed,sample

## Завдання: Сума семи
Оцініть імовірність того, що сума двох кубиків дорівнює 7: зробіть 10 000 дослідів (`replicate`) і збережіть частку в `p7`. Теоретично це `1/6`.
```r starter
# set.seed(42)
# sums <- replicate(...)
# p7 <- ...

```
```r solution
set.seed(42)
sums <- replicate(10000, sum(sample(1:6, 2, replace = TRUE)))
p7 <- mean(sums == 7)
```
@hint У кожному досліді: `sum(sample(1:6, 2, replace = TRUE))`.
@hint Частка подій — `mean(sums == 7)`.
@check uses=replicate
@test exists("p7") && abs(p7 - 1/6) < 0.02 => p7 має бути близьким до 1/6 ≈ 0.167.

## Завдання: Випадкові рядки
Зафіксуйте `set.seed(10)`, виберіть 5 випадкових рядків набору `iris` (індекси `sample(nrow(iris), 5)`) і збережіть у `s`.
```r starter
# set.seed(10)
# idx <- ...
# s <- ...

```
```r solution
set.seed(10)
idx <- sample(nrow(iris), 5)
s <- iris[idx, ]
```
@hint Спершу індекси, потім `iris[idx, ]`.
@check vars=s

## Завдання: Вибірка з вагами
Згенеруйте 1000 значень із `c("A", "B", "C")` з ймовірностями 0.5, 0.3, 0.2 (`prob`, з поверненням, `set.seed(5)`) — вектор `grp`.
```r starter
# set.seed(5)
# grp <- ...

```
```r solution
set.seed(5)
grp <- sample(c("A", "B", "C"), 1000, replace = TRUE, prob = c(0.5, 0.3, 0.2))
```
@hint `sample(x, size, replace = TRUE, prob = ...)`.
@check uses=sample
@test length(grp) == 1000 && all(abs(prop.table(table(grp)) - c(0.5, 0.3, 0.2)) < 0.06) => Довжина має бути 1000, а частки — близькими до 0.5/0.3/0.2.

## Завдання: Нормальна вибірка
Згенеруйте 1000 значень з нормального розподілу із середнім 50 та стандартним відхиленням 10 (`set.seed(2024)`) — вектор `x`.
```r starter
# set.seed(2024)
# x <- ...

```
```r solution
set.seed(2024)
x <- rnorm(1000, mean = 50, sd = 10)
```
@hint `rnorm(n, mean, sd)`.
@check uses=rnorm
@test length(x) == 1000 && abs(mean(x) - 50) < 1.5 && abs(sd(x) - 10) < 1 => Вибірка має містити 1000 значень із середнім ≈ 50 і sd ≈ 10.

## Тест: set.seed
Навіщо викликають `set.seed(...)`?
- [ ] щоб числа були «справді» випадковими
- [x] щоб результати симуляції можна було відтворити
- [ ] щоб прискорити генерацію
- [ ] без нього `sample()` не працює
@explain Одне й те саме зерно породжує ту саму послідовність псевдовипадкових чисел, тож інші люди зможуть отримати ваші самі результати.
