# Розподіли ймовірностей
> d, p, q, r: щільність, функція розподілу, квантиль, випадкові числа.

Для кожного розподілу в R є чотири функції з однаковою системою префіксів:

| Префікс | Що обчислює | Приклад для нормального |
|---|---|---|
| `d` | щільність / ймовірність у точці | `dnorm(x)` |
| `p` | функція розподілу `P(X ≤ x)` | `pnorm(x)` |
| `q` | квантиль (обернена до `p`) | `qnorm(p)` |
| `r` | випадкові числа | `rnorm(n)` |

### Нормальний розподіл

Нехай урожайність пшениці ~ N(6, 0.8²):

```r
pnorm(7, mean = 6, sd = 0.8)                       # P(X ≤ 7)
1 - pnorm(7, mean = 6, sd = 0.8)                   # P(X > 7)
pnorm(7, 6, 0.8) - pnorm(5, 6, 0.8)                # P(5 < X ≤ 7)
qnorm(0.95, mean = 6, sd = 0.8)                    # 95-й процентиль
pnorm(2) - pnorm(-2)                               # ≈ 95 % у межах ±2σ
```

### Біноміальний розподіл

Із 10 насінин кожна сходить з імовірністю 0.8:

```r
dbinom(8, size = 10, prob = 0.8)       # P(X = 8)
pbinom(7, size = 10, prob = 0.8)       # P(X ≤ 7)
1 - pbinom(7, 10, 0.8)                 # P(X ≥ 8)
```

### Розподіл Пуассона

Кількість шкідників на рослині в середньому λ = 2:

```r
dpois(0, lambda = 2)                   # P(X = 0)
1 - ppois(2, lambda = 2)               # P(X ≥ 3)
```

### Інші

```r
punif(0.3, 0, 1)                       # рівномірний
pexp(1, rate = 0.5)                    # експоненціальний
qt(0.975, df = 10)                     # критичне значення t
qchisq(0.95, df = 3)
```

### Візуалізація щільності

```r
curve(dnorm(x, 6, 0.8), 3, 9, lwd = 2, col = "blue", ylab = "щільність")
abline(v = 6, lty = 2)
```

## Завдання: Імовірність перевищення
Урожайність ~ N(6, 0.8). Знайдіть ймовірність, що вона **перевищить 7 т/га**, у змінну `p`.
```r starter
# p <- ...

```
```r solution
p <- 1 - pnorm(7, mean = 6, sd = 0.8)
```
@hint Функція `pnorm` дає `P(X ≤ x)`; додаткова подія — `1 - ...`.
@check vars=p uses=pnorm

## Завдання: Процентиль
Знайдіть значення урожайності, нижче якого лежить 90 % випадків для N(6, 0.8) — змінна `q90`.
```r starter
# q90 <- ...

```
```r solution
q90 <- qnorm(0.9, mean = 6, sd = 0.8)
```
@hint Для квантилів префікс `q`.
@check vars=q90 uses=qnorm

## Завдання: Схожість насіння
Із 10 насінин кожна сходить з імовірністю 0.8. Знайдіть `p8` — імовірність рівно 8 сходів, та `p_le7` — імовірність не більше 7 сходів.
```r starter
# p8 <- dbinom(...)
# p_le7 <- pbinom(...)

```
```r solution
p8 <- dbinom(8, size = 10, prob = 0.8)
p_le7 <- pbinom(7, size = 10, prob = 0.8)
```
@hint `d` — для точкової ймовірності, `p` — для накопиченої.
@check vars=p8,p_le7

## Завдання: Шкідники
Кількість шкідників на рослині ~ Пуассон(λ = 2). Знайдіть імовірність відсутності шкідників `p0` та імовірність трьох і більше шкідників `p3plus`.
```r starter
# p0 <- ...
# p3plus <- ...

```
```r solution
p0 <- dpois(0, lambda = 2)
p3plus <- 1 - ppois(2, lambda = 2)
```
@hint `P(X ≥ 3) = 1 − P(X ≤ 2)`.
@check vars=p0,p3plus

## Завдання: Емпірика проти теорії
Згенеруйте 10 000 стандартних нормальних чисел (`set.seed(1)`) у вектор `z`, знайдіть частку значень менших за 1 у змінній `frac` і порівняйте з теоретичним `pnorm(1)`.
```r starter
# set.seed(1)
# z <- ...
# frac <- ...

```
```r solution
set.seed(1)
z <- rnorm(10000)
frac <- mean(z < 1)
```
@hint Частка — середнє логічного вектора.
@check uses=rnorm
@test length(z) == 10000 && abs(frac - pnorm(1)) < 0.02 => frac має бути близьким до pnorm(1) ≈ 0.841.

## Тест: Префікси
Що обчислює `qnorm(0.975)`?
- [ ] щільність у точці 0.975
- [ ] ймовірність того, що `X ≤ 0.975`
- [x] значення `x`, для якого `P(X ≤ x) = 0.975`
- [ ] 0.975 випадкових чисел
@explain `q` — квантильна функція, обернена до функції розподілу. Для стандартного нормального `qnorm(0.975) ≈ 1.96`.
