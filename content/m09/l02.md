# Тести для категоріальних даних
> χ²-тест, пропорції та точний біноміальний тест.

### χ² для відповідності розподілу

Чи збігаються спостережувані частоти з очікуваними? Нехай серед 100 рослин спостерігали три фенотипи, а теорія очікує співвідношення 50 : 30 : 20:

```r
observed <- c(48, 35, 17)
chisq.test(observed, p = c(0.5, 0.3, 0.2))
```

### χ² для незалежності

Чи пов'язані дві категоріальні ознаки? Таблиця спряженості:

```r
tab <- matrix(c(30, 10, 20, 40), nrow = 2,
              dimnames = list(обробка = c("так", "ні"), хвороба = c("є", "немає")))
tab
res <- chisq.test(tab)
res
res$expected      # очікувані частоти за H₀
res$p.value
```

Якщо очікувані частоти малі (< 5), краще скористатися точним тестом Фішера: `fisher.test(tab)`.

### Тести для часток

```r
# 45 з 120 насінин зійшли. Чи відрізняється частка від 0.5?
prop.test(45, 120, p = 0.5)
# точний біноміальний тест
binom.test(7, 10, p = 0.5)
# порівняння двох часток
prop.test(c(45, 60), c(120, 130))
```

### Як вибрати тест

| Задача | Тест |
|---|---|
| частоти проти теорії | `chisq.test(x, p = ...)` |
| зв'язок двох категорій | `chisq.test(table)` / `fisher.test` |
| одна частка | `prop.test` / `binom.test` |
| дві частки | `prop.test(c(x1, x2), c(n1, n2))` |

## Завдання: Відповідність розподілу
Перевірте χ²-тестом, чи відповідають спостережені частоти `observed` теоретичному співвідношенню 50 : 30 : 20. P-значення — `p_gof`.
```r setup
observed <- c(48, 35, 17)
```
```r starter
# p_gof <- chisq.test(..., p = ...)$p.value

```
```r solution
p_gof <- chisq.test(observed, p = c(0.5, 0.3, 0.2))$p.value
```
@hint Теоретичні частки — аргумент `p`.
@check vars=p_gof uses=chisq.test

## Завдання: Незалежність
Для таблиці спряженості `tab` виконайте χ²-тест і збережіть p-значення в `p_ind`, а очікувані частоти — в `exp_counts`.
```r setup
tab <- matrix(c(30, 10, 20, 40), nrow = 2, dimnames = list(обробка = c("так", "ні"), хвороба = c("є", "немає")))
```
```r starter
# res <- chisq.test(tab)
# p_ind <- ...
# exp_counts <- ...

```
```r solution
res <- chisq.test(tab)
p_ind <- res$p.value
exp_counts <- res$expected
```
@hint Результат містить елементи `$p.value` та `$expected`.
@check vars=p_ind,exp_counts

## Завдання: Тест частки

```r starter
# p_prop <- prop.test(...)$p.value
```

## Завдання: Точний тест
З 10 дослідів 7 успішні. Виконайте точний біноміальний тест проти `p = 0.5` і збережіть p-значення в `p_binom`.
