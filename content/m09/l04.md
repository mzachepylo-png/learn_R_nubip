# Потужність, розмір вибірки та множинні порівняння
> Скільки спостережень потрібно і як не «знайти» ефект випадково.

### Помилки двох родів

| | H₀ правдива | H₀ хибна |
|---|---|---|
| відхилили H₀ | **помилка I роду** (α) | правильно (потужність 1 − β) |
| не відхилили | правильно | **помилка II роду** (β) |

Рівень значущості α зазвичай 0.05. **Потужність** — імовірність виявити реальний ефект.

### Потужність і розмір вибірки для t-тесту

```r
power.t.test(delta = 0.5, sd = 1, power = 0.8)       # скільки спостережень у групі?
power.t.test(n = 30, delta = 0.5, sd = 1)            # яка потужність при n = 30?
power.t.test(n = 20, sd = 1, power = 0.8)            # мінімальний виявний ефект
```

Параметр, який ви не задали, функція знаходить сама. `delta` — різниця середніх, `sd` — стандартне відхилення.

### Імітація: частота хибних спрацювань

Якщо H₀ правдива, p-значення рівномірно розподілені, тож приблизно 5 % тестів дадуть p < 0.05:

```r
set.seed(1)
p <- replicate(2000, t.test(rnorm(20), rnorm(20))$p.value)
mean(p < 0.05)
hist(p, breaks = 20)
```

### Множинні порівняння

Робити 20 тестів і радіти єдиному «значущому» — хибно: за H₀ очікується одне хибне спрацювання. Поправки:

```r
p <- c(0.001, 0.012, 0.03, 0.04, 0.2)
p.adjust(p, method = "bonferroni")
p.adjust(p, method = "holm")
p.adjust(p, method = "BH")        # контроль частки хибних відкриттів (FDR)
```

> 💡 Плануйте розмір вибірки **до** експерименту й заздалегідь визначайте, які гіпотези перевіряєте.

## Завдання: Хибні спрацювання
Змоделюйте 2000 t-тестів для двох вибірок по 20 значень з однакового нормального розподілу (`rnorm(20)`, `set.seed(1)`). У змінну `fpr` запишіть частку тестів із p < 0.05.
```r starter
# set.seed(1)
# p <- replicate(...)
# fpr <- ...

```
```r solution
set.seed(1)
p <- replicate(2000, t.test(rnorm(20), rnorm(20))$p.value)
fpr <- mean(p < 0.05)
```
@hint У кожному повторі: `t.test(rnorm(20), rnorm(20))$p.value`.
@check uses=replicate,t.test
@test exists("fpr") && abs(fpr - 0.05) < 0.02 => Частка хибних спрацювань має бути ≈ 0.05.
