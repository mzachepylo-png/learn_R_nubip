# Кореляція, ANOVA та непараметричні тести
> Порівняння кількох груп, зв'язок змінних та тести без припущення про нормальність.

### Тест кореляції

```r
ct <- cor.test(mtcars$mpg, mtcars$wt)
ct
ct$estimate      # коефіцієнт кореляції
ct$p.value
ct$conf.int
```

### Однофакторний дисперсійний аналіз (ANOVA)

Чи відрізняються середні кількох груп? Набір `PlantGrowth`: суха вага рослин у контролі й за двох обробок.

```r
boxplot(weight ~ group, data = PlantGrowth)
fit <- aov(weight ~ group, data = PlantGrowth)
summary(fit)
summary(fit)[[1]][["Pr(>F)"]][1]    # p-значення F-тесту
```

H₀: усі середні рівні. Якщо вона відхилена, парні порівняння виконує тест Тьюкі:

```r
TukeyHSD(fit)
round(TukeyHSD(fit)$group, 3)
```

### Перевірка нормальності та однорідності

```r
shapiro.test(mtcars$mpg)                       # H₀: дані нормальні
bartlett.test(weight ~ group, data = PlantGrowth)  # H₀: дисперсії рівні
```

### Непараметричні аналоги

Коли нормальність не виконується або дані порядкові:

| Параметричний | Непараметричний |
|---|---|
| одновибірковий / парний t-тест | `wilcox.test` (знакових рангів) |
| двовибірковий t-тест | `wilcox.test` (Манна–Вітні) |
| ANOVA | `kruskal.test` |
| кореляція Пірсона | `cor.test(method = "spearman")` |

```r
wilcox.test(mpg ~ am, data = mtcars, exact = FALSE)
kruskal.test(weight ~ group, data = PlantGrowth)
```

## Завдання: Кореляція з тестом
Виконайте тест кореляції `mpg` та `wt` у `mtcars`. Коефіцієнт кореляції — `r_est` (число без імені, `unname`), p-значення — `p_cor`.
```r starter
# ct <- cor.test(...)
# r_est <- ...
# p_cor <- ...

```
```r solution
ct <- cor.test(mtcars$mpg, mtcars$wt)
r_est <- unname(ct$estimate)
p_cor <- ct$p.value
```
@hint `unname()` прибирає назву `cor`.
@check vars=r_est,p_cor uses=cor.test
