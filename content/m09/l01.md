# Довірчі інтервали та t-тести
> Чи відрізняється середнє від заданого значення або одна група від іншої?

Статистичний тест перевіряє **нульову гіпотезу** H₀ (немає ефекту) проти альтернативи H₁. Результат — **p-значення**: імовірність отримати такі (або сильніші) дані, якщо H₀ правдива. Мале p (зазвичай < 0.05) — підстава відхилити H₀.

### Одновибірковий t-тест

Чи відрізняється середня витрата пального в `mtcars` від 20 миль на галон?

```r
res <- t.test(mtcars$mpg, mu = 20)
res
res$p.value
res$conf.int       # 95 % довірчий інтервал для середнього
res$estimate
```

### Двовибірковий тест (Велч)

Порівнюємо автомобілі з ручною (`am = 1`) та автоматичною (`am = 0`) коробкою:

```r
t.test(mpg ~ am, data = mtcars)
```

Формула `y ~ група` розбиває `y` на дві групи. За замовчуванням використовується тест Велча (не вимагає однакових дисперсій).

### Парний тест

Коли вимірювання зроблено на тих самих об'єктах двічі (до/після):

```r
before <- sleep$extra[sleep$group == 1]
after <- sleep$extra[sleep$group == 2]
t.test(before, after, paired = TRUE)
```

### Розмір ефекту

Значущість — не те саме, що важливість. Розмір ефекту (d Коена) показує різницю в одиницях стандартного відхилення:

```r
a <- mtcars$mpg[mtcars$am == 1]
b <- mtcars$mpg[mtcars$am == 0]
(mean(a) - mean(b)) / sqrt((var(a) + var(b)) / 2)
```

### Умови застосування

- спостереження незалежні (крім парного тесту);
- дані приблизно нормальні (при великих вибірках менш критично) — перевіряють `qqnorm`, `shapiro.test`;
- для двох груп — порівняйте розкид (`var.test`).

> ⚠️ p = 0.04 не означає «ефект існує з імовірністю 96 %». Це ймовірність даних за умови H₀.

## Завдання: Одновибірковий тест
Перевірте гіпотезу, що середня `mpg` у `mtcars` дорівнює 20. Збережіть p-значення в змінну `p1`.
```r starter
# p1 <- t.test(...)$p.value

```
```r solution
p1 <- t.test(mtcars$mpg, mu = 20)$p.value
```
@hint Нульове значення задається аргументом `mu`.
@check vars=p1 uses=t.test

## Завдання: Порівняння груп
Порівняйте середню `mpg` для автомобілів з автоматичною та ручною коробкою (`am`) тестом Велча: результат тесту запишіть у `tt`, p-значення — у `p_value`.
```r starter
# tt <- t.test(...)
# p_value <- ...

```
```r solution
tt <- t.test(mpg ~ am, data = mtcars)
p_value <- tt$p.value
```
@hint `t.test(mpg ~ am, data = mtcars)`.
@check vars=p_value uses=t.test

Для даних `sleep` порівняйте додаткові години сну `before` та `after` (ті самі пацієнти) парним t-тестом. P-значення — `p_paired`.

```r setup
before <- sleep$extra[sleep$group == 1]
```

## Завдання: 90 % інтервал
Знайдіть 90 % довірчий інтервал для середнього `mtcars$mpg` (аргумент `conf.level`). Збережіть його у `ci90` — вектор із двох чисел без додаткових атрибутів (`as.numeric`).
```r starter
# ci90 <- as.numeric(t.test(...)$conf.int)

```
```r solution
ci90 <- as.numeric(t.test(mtcars$mpg, conf.level = 0.90)$conf.int)
```

@check vars=ci90
