# Індексація вектора
> Вибирайте елементи за номером, умовою або іменем.

Для вибору елементів використовують квадратні дужки `[ ]`. Нумерація в R починається з **1**.

```r
temp <- c(18.5, 21, 19.5, 23, 25.5, 24, 20)
temp[3]          # третій елемент
temp[c(1, 5)]    # перший і п'ятий
temp[2:4]        # з 2-го по 4-й
temp[-1]         # усе, крім першого
temp[-c(1, 7)]   # без першого й сьомого
temp[length(temp)]  # останній
```

### Логічна індексація

Усередину дужок можна передати вектор `TRUE/FALSE` — залишаться елементи, де `TRUE`:

```r
temp > 22              # логічний вектор
temp[temp > 22]        # лише теплі дні
temp[temp > 20 & temp < 25]
which(temp > 22)       # номери позицій, де умова виконується
```

### Вибір за іменами та зміна елементів

```r
names(temp) <- c("Пн", "Вт", "Ср", "Чт", "Пт", "Сб", "Нд")
temp["Пт"]
names(temp)[temp > 22]     # назви «теплих» днів
temp["Ср"] <- 20           # змінити значення
temp[temp < 20] <- 20      # замінити всі, що менші за 20
temp
```

### Корисне

```r
x <- c(5, 8, 2, 9, 4)
head(x, 2)        # перші 2
tail(x, 2)        # останні 2
which.max(x)      # позиція максимуму
c(8, 7) %in% x    # чи входять значення у вектор
```

## Завдання: Третій елемент
Із вектора `temp` візьміть третій елемент і збережіть у змінну `third`.
```r setup
temp <- c(18.5, 21, 19.5, 23, 25.5, 24, 20)
```
```r starter
# third <- temp[...]

```
```r solution
third <- temp[3]
```
@hint Індекс у квадратних дужках: `temp[3]`.
@check vars=third

## Завдання: Без першого та останнього
Створіть вектор `middle` — усі температури, крім першої та останньої. Не вписуйте числа вручну: скористайтеся `length(temp)`.
```r setup
temp <- c(18.5, 21, 19.5, 23, 25.5, 24, 20)
```
```r starter
# middle <- temp[...]

```
```r solution
middle <- temp[-c(1, length(temp))]
```
@hint Мінус перед індексами виключає елементи: `temp[-c(1, 7)]`.
@hint Номер останнього елемента дорівнює `length(temp)`.
@check vars=middle uses=length

## Завдання: Спекотні дні
Виберіть із `temp` лише значення більші за 22 — у змінну `hot`, а кількість таких днів — у `n_hot`.
```r setup
temp <- c(18.5, 21, 19.5, 23, 25.5, 24, 20)
```
```r starter
# hot <- ...
# n_hot <- ...

```
```r solution
hot <- temp[temp > 22]
n_hot <- length(hot)
```
@hint Логічна умова всередині дужок: `temp[temp > 22]`.
@check vars=hot,n_hot

## Завдання: Назви днів
Вектор `temp` уже має імена днів. Збережіть у `hot_days` назви днів із температурою вище 22.
```r setup
temp <- c(18.5, 21, 19.5, 23, 25.5, 24, 20)
names(temp) <- c("Пн", "Вт", "Ср", "Чт", "Пт", "Сб", "Нд")
```
```r starter
# hot_days <- names(temp)[...]

```
```r solution
hot_days <- names(temp)[temp > 22]
```
@hint `names(temp)` — вектор назв; його теж можна індексувати логічною умовою.
@check vars=hot_days

## Завдання: Поправка датчика
Датчик занижує значення нижче 20 градусів на 0.5. Збільште на 0.5 лише ті елементи `temp`, що менші за 20. Результат має лишитися в `temp`.
```r setup
temp <- c(18.5, 21, 19.5, 23, 25.5, 24, 20)
```
```r starter
# temp[...] <- ...

```
```r solution
temp[temp < 20] <- temp[temp < 20] + 0.5
```
@hint Присвоєння в індексований підвектор: `temp[умова] <- нові_значення`.
@check vars=temp

## Тест: Логічна індексація
Нехай `x <- c(5, 8, 2, 9, 4)`. Що поверне `x[x > 4 & x < 9]`?
- [ ] `8 9`
- [x] `5 8`
- [ ] `5 8 4`
- [ ] `TRUE TRUE FALSE FALSE FALSE`
@explain Умова `x > 4 & x < 9` істинна для 5 і 8 (9 не менше 9, 4 не більше 4). Вибираються самі значення, а не логічні прапорці.
