# Статистика вектора
> Середнє, розкид, квантилі, накопичення та сортування — одним викликом.

Чимало вбудованих функцій приймають вектор і повертають одне число (або новий вектор):

| Функція | Що робить |
|---|---|
| `sum`, `prod` | сума, добуток |
| `mean`, `median` | середнє, медіана |
| `sd`, `var` | стандартне відхилення, дисперсія |
| `min`, `max`, `range` | мінімум, максимум, діапазон |
| `cumsum`, `cumprod` | накопичувальні сума й добуток |
| `diff` | різниці сусідніх елементів |
| `sort`, `order`, `rev` | сортування, порядок індексів, розворот |
| `quantile`, `summary` | квантилі, зведення |

```r
yield <- c(5.8, 6.1, 5.4, 6.9, 7.2, 6.4, 5.9, 6.6)
mean(yield)
median(yield)
sd(yield)
range(yield)
summary(yield)
quantile(yield, c(0.25, 0.75))
```

### Накопичення і різниці

```r
rain <- c(30, 12, 0, 45, 20)
cumsum(rain)    # накопичені опади
diff(rain)      # зміна між сусідніми вимірами
```

### Сортування

```r
sort(yield)                       # за зростанням
sort(yield, decreasing = TRUE)    # за спаданням
order(yield, decreasing = TRUE)   # у якому порядку брати індекси
yield[order(yield)][1:3]          # три найменші
```

### Пропущені значення

Якщо у векторі є `NA`, більшість функцій теж повертають `NA`. Додайте `na.rm = TRUE`, щоб проігнорувати пропуски:

```r
x <- c(4.2, NA, 5.1, 6.3, NA, 5.5)
mean(x)
mean(x, na.rm = TRUE)
sum(is.na(x))      # скільки пропусків
```

### Стандартизація (z-оцінки)

Щоб порівнювати величини в різних шкалах, віднімають середнє й ділять на стандартне відхилення:

```r
z <- (yield - mean(yield)) / sd(yield)
round(z, 2)
```

## Завдання: Середнє та розкид
Обчисліть середнє значення `yield` у змінну `m` та стандартне відхилення у змінну `s`.

## Завдання: Накопичені опади
Щомісячні опади задано вектором `rain`. Створіть `cum_rain` — накопичені опади та `change` — зміну опадів від місяця до місяця (функція `diff`).
```r setup
rain <- c(30, 12, 0, 45, 20, 8)
```
```r starter
# cum_rain <- ...
# change <- ...

```
```r solution
cum_rain <- cumsum(rain)
change <- diff(rain)
```
@hint Накопичена сума — `cumsum()`, а різниці сусідніх елементів — `diff()`.
@check vars=cum_rain,change

## Завдання: Топ-3 урожаї
