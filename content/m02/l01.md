# Створення векторів
> Вектор — основа R: впорядкований набір значень одного типу.

У R навіть одне число — це вектор довжини 1. Вектори створюють функцією `c()` (від *combine*):

```r
temp <- c(18.5, 21, 19.5, 23, 25.5)   # числовий вектор
crops <- c("пшениця", "ячмінь", "соя") # текстовий
flags <- c(TRUE, FALSE, TRUE)          # логічний
length(temp)                           # кількість елементів
class(crops)
```

> ⚠️ Усі елементи вектора мають **один тип**. Якщо змішати, R приведе їх до «найширшого»: `c(1, "a", TRUE)` стане текстовим.

### Послідовності та повтори

```r
1:10                      # цілі від 1 до 10
10:1                      # у зворотному порядку
seq(0, 100, by = 25)      # з кроком
seq(0, 1, length.out = 5) # задана кількість точок
rep(c("A", "B"), times = 3)   # повторити весь вектор
rep(c(1, 2), each = 3)        # повторити кожен елемент
```

### Арифметика над векторами

Операції виконуються **поелементно** — цикли не потрібні:

```r
price <- c(12, 15, 9.5, 20)
qty <- c(100, 80, 150, 40)
revenue <- price * qty
revenue
sum(revenue)
price * 1.2      # число «розтягується» на весь вектор
```

Якщо вектори різної довжини, коротший **перевикористовується циклічно** (правило рециклінгу). Коли довжини не кратні — R попереджає:

```r
c(1, 2, 3, 4) + c(10, 20)       # (11, 22, 13, 24)
c(1, 2, 3) + c(10, 20)          # попередження
```

### Імена елементів

```r
yield <- c(wheat = 6.2, barley = 5.1, maize = 9.8)
yield
names(yield)
yield["maize"]
names(yield) <- c("пшениця", "ячмінь", "кукурудза")  # перейменування
yield
```

## Завдання: Температури тижня
Створіть числовий вектор `temp` з денними температурами тижня: `18.5, 21, 19.5, 23, 25.5, 24, 20`.
```r starter
# temp <- c(...)

```
```r solution
temp <- c(18.5, 21, 19.5, 23, 25.5, 24, 20)
```
@hint Значення записуються через кому всередині `c()`.
@check vars=temp

## Завдання: Послідовності
Створіть два вектори: `years` — цілі числа від 2015 до 2024 та `grid` — 5 рівновіддалених точок від 0 до 2 (використайте `length.out`).
```r starter
# years <- ...
# grid <- ...

```
```r solution
years <- 2015:2024
grid <- seq(0, 2, length.out = 5)
```
@hint Для цілих підряд найкоротший запис — оператор `:`.
@hint `seq(0, 2, length.out = 5)`.
@check vars=years,grid

## Завдання: Схема досліду
У польовому досліді є 2 варіанти (`"контроль"` та `"добриво"`), по 4 повторення кожного. Створіть:

- `treatment` — `"контроль"` ×4, потім `"добриво"` ×4;
- `block` — номери повторень `1, 2, 3, 4`, що повторюються двічі.
```r starter
# treatment <- rep(...)
# block <- rep(...)

```
```r solution
treatment <- rep(c("контроль", "добриво"), each = 4)
block <- rep(1:4, times = 2)
```
@hint Для `treatment` потрібен аргумент `each`, для `block` — `times`.
@check vars=treatment,block

## Завдання: Виручка
Задано ціни `price` та кількості `qty`. Обчисліть вектор виручки `revenue` (ціна × кількість) і загальну виручку `total_revenue`.
```r setup
price <- c(12, 15, 9.5, 20)
qty <- c(100, 80, 150, 40)
```
```r starter
# revenue <- ...
# total_revenue <- ...

```
```r solution
revenue <- price * qty
total_revenue <- sum(revenue)
```
@hint Множення векторів виконується поелементно: `price * qty`.
@check vars=revenue,total_revenue

## Завдання: Іменований вектор
Створіть вектор `yield` з іменованими елементами: `wheat = 6.2`, `barley = 5.1`, `maize = 9.8`.
```r starter
# yield <- c(wheat = ..., ...)

```
```r solution
yield <- c(wheat = 6.2, barley = 5.1, maize = 9.8)
```
@hint Імена задаються прямо в `c()`: `c(wheat = 6.2, ...)`.
@check vars=yield
