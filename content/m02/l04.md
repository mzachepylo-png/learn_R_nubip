# Логіка та умови над векторами
> Порівнюйте, рахуйте й класифікуйте одразу цілі набори значень.

Порівняння та логічні оператори теж **векторизовані**: результат — логічний вектор тієї ж довжини.

```r
temp <- c(18.5, 21, 19.5, 23, 25.5, 24, 20)
temp > 22
temp >= 20 & temp <= 24
temp < 19 | temp > 25
!(temp > 22)
```

### Підрахунок через логічні значення

`TRUE` дорівнює 1, а `FALSE` — 0, тому:

```r
sum(temp > 22)     # скільки днів тепліше за 22
mean(temp > 22)    # яка частка таких днів
any(temp > 25)     # чи є хоч один день > 25
all(temp > 15)     # чи всі дні > 15
```

### Умовне значення: ifelse

`ifelse(умова, якщо_так, якщо_ні)` працює над усім вектором:

```r
ifelse(temp >= 23, "спека", "норма")
ifelse(temp > 22, temp, NA)
```

### Пошук екстремумів і належності

```r
names(temp) <- c("Пн", "Вт", "Ср", "Чт", "Пт", "Сб", "Нд")
which.max(temp)             # позиція (з іменем) максимуму
names(temp)[which.max(temp)]
which.min(temp)
crops <- c("пшениця", "ячмінь", "соя")
c("соя", "рис") %in% crops  # чи входить кожен елемент
```

> 💡 Для порівняння на рівність у векторах використовуйте `==`, а не `=` (це присвоєння).

## Завдання: Скільки спекотних днів
Порахуйте, у скількох днях температура `temp` перевищує 22 градуси: збережіть число в `n_hot` і виведіть його.
```r setup
temp <- c(18.5, 21, 19.5, 23, 25.5, 24, 20)
```
```r starter
# n_hot <- ...
# n_hot

```
```r solution
n_hot <- sum(temp > 22)
n_hot
```
@hint Логічні значення можна підсумовувати: `sum(temp > 22)`.
@check vars=n_hot output

## Завдання: Частка врожайних ділянок
Яка частка ділянок має урожайність вище 6 т/га? Обчисліть через `mean()` від логічного вектора і виведіть результат.
```r setup
yield <- c(5.8, 6.1, 5.4, 6.9, 7.2, 6.4, 5.9, 6.6)
```
```r starter
# mean(...)

```

```r solution
mean(yield > 6)
```
@hint Середнє логічного вектора — це частка `TRUE`.
@check output uses=mean

## Завдання: Класифікація
Створіть текстовий вектор `category`: `"спека"`, якщо температура ≥ 23, інакше `"норма"`. Використайте `ifelse()`.
```r setup
temp <- c(18.5, 21, 19.5, 23, 25.5, 24, 20)
```
```r starter
# category <- ifelse(...)

```
```r solution
category <- ifelse(temp >= 23, "спека", "норма")
```
@hint Перший аргумент — умова: `temp >= 23`.
@check vars=category uses=ifelse

## Завдання: any та all
Виведіть (по черзі): чи є хоч один день зі `temp` вище 25, і чи всі дні вищі за 15.
```r setup
temp <- c(18.5, 21, 19.5, 23, 25.5, 24, 20)
```
```r starter
# any(...)
# all(...)

```
```r solution
any(temp > 25)
all(temp > 15)
```
@hint Функція `any` — «хоч один», `all` — «усі».
@check output uses=any,all

## Завдання: Чи є культура в сівозміні
Для кожної культури зі списку `candidates` визначте, чи входить вона до `rotation`. Виведіть логічний вектор.
```r setup
rotation <- c("пшениця", "ячмінь", "соя", "кукурудза")
```
