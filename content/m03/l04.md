# Моделі на матрицях
> Міжгалузевий баланс Леонтьєва, марковські ланцюги та регресія через нормальні рівняння.

Матриці — це мова багатьох математичних моделей. Розглянемо три класичні приклади.

### 1. Міжгалузевий баланс (модель Леонтьєва)

Дві галузі виробляють продукцію для внутрішнього споживання й для кінцевого попиту `d`. Матриця `A` показує, скільки продукції галузі *i* витрачається на одиницю продукції галузі *j*. Валовий випуск `x` задовольняє `x = A·x + d`, звідки `x = (I − A)⁻¹ · d`:

```r
A <- matrix(c(0.2, 0.3,
              0.4, 0.1), nrow = 2, byrow = TRUE)
d <- c(100, 50)
x <- solve(diag(2) - A, d)
x
```

### 2. Марковський ланцюг

Ймовірності переходу між станами «ясно» та «дощ» записують у матриці `P` (рядки — звідки, стовпці — куди; кожен рядок дає в сумі 1). Розподіл ймовірностей на наступному кроці: `s %*% P`.

```r
P <- matrix(c(0.8, 0.2,
              0.4, 0.6), nrow = 2, byrow = TRUE,
            dimnames = list(c("ясно", "дощ"), c("ясно", "дощ")))
s <- c(1, 0)             # сьогодні точно ясно
for (i in 1:3) s <- s %*% P
s                        # розподіл через 3 дні
```

Довгострокову (стаціонарну) поведінку дає власний вектор транспонованої матриці для власного числа 1:

```r
ev <- eigen(t(P))
st <- Re(ev$vectors[, 1])
st / sum(st)
```

### 3. Регресія через нормальні рівняння

Для моделі `y = β₀ + β₁·x` оцінки найменших квадратів: `β = (XᵀX)⁻¹ Xᵀy`, де `X` має стовпець одиниць:

```r
x <- c(1, 2, 3, 4, 5)
y <- c(2.1, 3.9, 6.2, 7.8, 10.1)
X <- cbind(1, x)
beta <- solve(t(X) %*% X, t(X) %*% y)
beta
coef(lm(y ~ x))     # перевірка вбудованою функцією
```

## Завдання: Баланс Леонтьєва
Для матриці прямих витрат `A` і вектора кінцевого попиту `d` знайдіть валовий випуск `x = (I − A)⁻¹ d`. Збережіть у змінну `x`. Скористайтеся `solve()` та `diag()`.
```r setup
A <- matrix(c(0.2, 0.3, 0.1,
              0.1, 0.2, 0.2,
              0.3, 0.1, 0.1), nrow = 3, byrow = TRUE)
d <- c(60, 40, 30)
```
```r starter
# x <- solve(..., d)

```
@hint Одинична матриця потрібного розміру — `diag(3)`.
@hint `solve(diag(3) - A, d)`.

## Завдання: Стаціонарний розподіл
Для матриці переходів `P` знайдіть стаціонарний розподіл `st` (вектор, що в сумі дає 1): власний вектор `t(P)` для найбільшого власного числа, нормований на суму. Використайте `eigen()`.
```r setup
P <- matrix(c(0.9, 0.1,
              0.5, 0.5), nrow = 2, byrow = TRUE)
```
```r starter
# ev <- eigen(t(P))
# st <- ...

```
```r solution
ev <- eigen(t(P))
st <- Re(ev$vectors[, 1])
st <- st / sum(st)
```
@hint `eigen(t(P))$vectors[, 1]` — вектор для найбільшого власного числа (беріть `Re()` — дійсну частину).
@hint Нормування: поділіть на суму компонент.
@check uses=eigen
@test isTRUE(all.equal(as.vector(st), as.vector(.sol$st))) => Вектор st має збігатися з очікуваним стаціонарним розподілом.
