# Індексація матриць і apply
> Беріть рядки, стовпці та окремі клітинки, рахуйте підсумки по осях.

Для матриці індекс має вигляд `[рядок, стовпець]`. Порожнє місце означає «усі».

```r
Y <- matrix(c(5.1, 5.8, 6.2, 5.4,
              4.9, 5.5, 6.0, 5.2,
              6.0, 6.4, 6.9, 6.1), nrow = 3, byrow = TRUE)
rownames(Y) <- c("Поле 1", "Поле 2", "Поле 3")
colnames(Y) <- 2021:2024

Y[2, 3]          # клітинка
Y[1, ]           # перший рядок
Y[, "2022"]      # стовпець за ім'ям
Y[1:2, c(1, 4)]  # блок
Y[-1, ]          # без першого рядка
```

> ⚠️ Вибір одного рядка/стовпця повертає **вектор**. Щоб зберегти матрицю, додайте `drop = FALSE`: `Y[1, , drop = FALSE]`.

### Логіка над матрицею

```r
Y > 6                  # логічна матриця
Y[Y > 6]               # значення, більші за 6 (вектор)
sum(Y < 5.5)           # скільки клітинок менші за 5.5
which(Y == max(Y), arr.ind = TRUE)   # позиція максимуму
```

### Підсумки по рядках і стовпцях

```r
rowSums(Y)
colMeans(Y)
rowMeans(Y)
```

### apply — довільна функція по осі

`apply(матриця, вісь, функція)`: вісь `1` — по рядках, `2` — по стовпцях.

```r
apply(Y, 1, max)           # максимум кожного поля
apply(Y, 2, sd)            # розкид по роках
apply(Y, 1, which.max)     # номер кращого року для поля
apply(Y, 2, function(col) max(col) - min(col))  # власна функція
```

## Завдання: Одна клітинка
З матриці `Y` візьміть значення в **другому** рядку та **третьому** стовпці й виведіть його.
```r setup
Y <- matrix(c(5.1, 5.8, 6.2, 5.4, 4.9, 5.5, 6.0, 5.2, 6.0, 6.4, 6.9, 6.1), nrow = 3, byrow = TRUE)
```
```r starter
# Y[..., ...]

```
```r solution
Y[2, 3]
```
@hint Спочатку номер рядка, потім стовпця: `Y[2, 3]`.
@check output

## Завдання: Середня урожайність по роках
Створіть вектор `year_mean` — середнє значення кожного стовпця матриці `Y` (по роках).
```r setup
Y <- matrix(c(5.1, 5.8, 6.2, 5.4, 4.9, 5.5, 6.0, 5.2, 6.0, 6.4, 6.9, 6.1), nrow = 3, byrow = TRUE)
colnames(Y) <- 2021:2024
```
```r starter
# year_mean <- ...

```
```r solution
year_mean <- colMeans(Y)
```
@hint Для середніх по стовпцях є функція `colMeans()`.
@check vars=year_mean

## Завдання: Найкращий рік
Для кожного поля (рядка) визначте номер стовпця з найбільшою урожайністю: вектор `best_year`. Використайте `apply()` та `which.max`.
```r setup
Y <- matrix(c(5.1, 5.8, 6.2, 5.4, 4.9, 5.5, 6.0, 5.2, 6.0, 6.4, 6.9, 6.1), nrow = 3, byrow = TRUE)
```
```r starter
# best_year <- apply(...)

```
```r solution
best_year <- apply(Y, 1, which.max)
```
@hint Вісь `1` означає «по рядках».
@check vars=best_year uses=apply

## Завдання: Низькі врожаї
Скільки клітинок матриці `Y` мають значення менше за 5.5? Збережіть число в `n_low`.
```r setup
Y <- matrix(c(5.1, 5.8, 6.2, 5.4, 4.9, 5.5, 6.0, 5.2, 6.0, 6.4, 6.9, 6.1), nrow = 3, byrow = TRUE)
```
```r starter
# n_low <- ...

```
```r solution
n_low <- sum(Y < 5.5)
```
@hint `Y < 5.5` дає логічну матрицю, а `sum()` порахує `TRUE`.
@check vars=n_low

## Завдання: Розмах по роках
Для кожного стовпця матриці `Y` обчисліть розмах (максимум мінус мінімум) — вектор `spread`. Використайте `apply()` із власною функцією.
```r setup
Y <- matrix(c(5.1, 5.8, 6.2, 5.4, 4.9, 5.5, 6.0, 5.2, 6.0, 6.4, 6.9, 6.1), nrow = 3, byrow = TRUE)
```
```r starter
# spread <- apply(Y, 2, function(col) ...)

```
```r solution
spread <- apply(Y, 2, function(col) max(col) - min(col))
```
@hint Власна функція: `function(col) max(col) - min(col)`.
@check vars=spread uses=apply
