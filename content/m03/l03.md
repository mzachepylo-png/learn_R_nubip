# Матричні операції
> Множення, транспонування, обернена матриця та розв'язання систем рівнянь.

Звичайні оператори `+ - * /` працюють над матрицями **поелементно**. Справжнє матричне множення — `%*%`:

```r
A <- matrix(c(2, 1, 1, 3), nrow = 2)
B <- matrix(c(1, 0, 4, 2), nrow = 2)
A * B      # поелементно
A %*% B    # матричний добуток
t(A)       # транспонування
```

Правило розмірів: (n×k) %*% (k×m) = (n×m). Якщо кількість стовпців першої не дорівнює кількості рядків другої — буде помилка `non-conformable`.

### Визначник, обернена матриця, діагональ

```r
det(A)          # визначник
solve(A)        # обернена матриця
A %*% solve(A)  # одинична (з похибкою округлення)
diag(A)         # діагональ
```

### Системи лінійних рівнянь

Система `2x + y = 5`, `x + 3y = 10` у матричній формі `A·x = b`:

```r
A <- matrix(c(2, 1,
              1, 3), nrow = 2, byrow = TRUE)
b <- c(5, 10)
solve(A, b)    # розв'язок (x, y)
```

### Зовнішній добуток

```r
outer(1:3, 1:4)             # таблиця множення
outer(1:3, 1:3, "+")        # будь-яка функція
crossprod(A)                # t(A) %*% A
```

> 💡 Не плутайте: `A %*% B` — матричний добуток, `A * B` — множення елемент на елемент.

## Завдання: Добуток матриць
Обчисліть матричний добуток `P` матриць `A` і `B`.
```r setup
A <- matrix(c(1, 2, 3, 4, 5, 6), nrow = 2)
B <- matrix(c(1, 0, 2, 1, 0, 3), nrow = 3)
```
```r starter
# P <- ...

```
```r solution
P <- A %*% B
```
@hint Матричний добуток записується як `A %*% B`.
@check vars=P

## Завдання: Транспонування та Грам
Для матриці `X` обчисліть `G` — добуток `t(X) %*% X` (матриця Грама).
```r setup
X <- matrix(c(1, 1, 1, 2, 3, 5), nrow = 3)
```
```r starter
# G <- ...

```
```r solution
G <- t(X) %*% X
```
@hint Функція `t()` транспонує матрицю.
@check vars=G

## Завдання: Система рівнянь
Розв'яжіть систему `3x + 2y = 12`, `x - y = 1`. Збережіть розв'язок (вектор з `x` і `y`) у змінну `sol`.
```r setup
A <- matrix(c(3, 2,
              1, -1), nrow = 2, byrow = TRUE)
b <- c(12, 1)
```
```r starter
# sol <- solve(...)

```
```r solution
sol <- solve(A, b)
```
@hint `solve(A, b)` розв'язує систему `A · x = b`.
@check vars=sol uses=solve

## Завдання: Визначник
Обчисліть визначник матриці `M` і округліть до 3 знаків після коми; результат збережіть у `d`.
```r setup
M <- matrix(c(4, 2, 7, 6, 1, 3, 2, 5, 8), nrow = 3)
```
```r starter
# d <- round(det(M), 3)

```

```r solution
d <- round(det(M), 3)
```
@hint Функція `det()`; округлення — `round(x, 3)`.
@check vars=d uses=det

## Завдання: Таблиця множення
Створіть матрицю `tbl` розміру 5×5 — таблицю множення від 1 до 5 за допомогою `outer()`.

## Тест: Розміри добутку
Матриця `A` має розмір 2×3, а `B` — 3×4. Який розмір має `A %*% B`?
- [ ] 3×3
- [x] 2×4
- [ ] 3×4
- [ ] добуток не визначений
@explain Кількість стовпців першої (3) збігається з кількістю рядків другої (3), а результат має рядки першої (2) і стовпці другої (4).
