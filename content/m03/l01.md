# Створення матриць
> Матриця — це вектор, у якого є рядки й стовпці.

Матриця зберігає елементи **одного типу** у двовимірній сітці. Створює її функція `matrix()`:

```r
A <- matrix(1:6, nrow = 2)     # заповнення по стовпцях (за замовчуванням)
A
B <- matrix(1:6, nrow = 2, byrow = TRUE)   # заповнення по рядках
B
dim(A)        # розмірність: рядки, стовпці
nrow(A); ncol(A)
```

### Склеювання вектор → матриця

`rbind()` складає вектори як **рядки**, `cbind()` — як **стовпці**:

```r
v1 <- c(1, 2, 3)
v2 <- c(4, 5, 6)
rbind(v1, v2)
cbind(v1, v2)
```

### Імена рядків і стовпців

```r
Y <- matrix(c(5.1, 5.8, 6.2, 5.4,
              4.9, 5.5, 6.0, 5.2,
              6.0, 6.4, 6.9, 6.1), nrow = 3, byrow = TRUE)
rownames(Y) <- c("Поле 1", "Поле 2", "Поле 3")
colnames(Y) <- 2021:2024
Y
```

### Спеціальні матриці

```r
diag(3)             # одинична 3 × 3
matrix(0, 2, 2)     # нульова
diag(c(2, 5, 7))    # діагональна
```

> 💡 Матриця — це вектор із атрибутом `dim`. Тому `length(Y)` — кількість усіх елементів (12).

## Завдання: Матриця 2×3
Створіть матрицю `A` із двох рядків і трьох стовпців із значень `2, 4, 6, 1, 3, 5`, заповнивши її **по рядках**.
```r starter
# A <- matrix(...)

```
```r solution
A <- matrix(c(2, 4, 6, 1, 3, 5), nrow = 2, byrow = TRUE)
```
@hint Потрібні аргументи `nrow = 2` і `byrow = TRUE`.
@check vars=A

## Завдання: Склеювання
Із векторів `v1` і `v2` складіть матрицю `M`, де вони є **рядками**.
```r setup
v1 <- c(10, 20, 30)
v2 <- c(1, 2, 3)
```
```r starter
# M <- ...

```
```r solution
M <- rbind(v1, v2)
```
@hint Рядки додає `rbind()` (від *row bind*).
@check vars=M

## Завдання: Врожайність по полях
Із вектора `values` створіть матрицю `Y` розмірів 3×4 (заповнення по рядках). Дайте рядкам імена `"Поле 1"`, `"Поле 2"`, `"Поле 3"`, а стовпцям — `2021`…`2024` (як числа через `rownames`/`colnames` або `dimnames`).
```r setup
values <- c(5.1, 5.8, 6.2, 5.4, 4.9, 5.5, 6.0, 5.2, 6.0, 6.4, 6.9, 6.1)
```
```r starter
# Y <- matrix(...)
# rownames(Y) <- ...
# colnames(Y) <- ...

```
```r solution
Y <- matrix(values, nrow = 3, byrow = TRUE)
rownames(Y) <- c("Поле 1", "Поле 2", "Поле 3")
colnames(Y) <- 2021:2024
```
@hint Спершу `matrix(values, nrow = 3, byrow = TRUE)`, потім імена.
@hint Імена стовпців: `colnames(Y) <- 2021:2024`.
@check vars=Y

## Завдання: Розмірність
Виведіть розмірність матриці `A` (кількість рядків і стовпців) однією функцією.
```r setup
A <- matrix(1:12, nrow = 3)
```
```r starter
# ...

```
```r solution
dim(A)
```
@hint Функція `dim()` повертає вектор із двох чисел.
@check output uses=dim

## Завдання: Одинична і нульова матриці
Створіть одиничну матрицю `I` розміру 3×3 та нульову матрицю `Z` розміру 2×4.
```r starter
# I <- ...
# Z <- ...

```
```r solution
I <- diag(3)
Z <- matrix(0, nrow = 2, ncol = 4)
```
@hint Одинична матриця створюється `diag(n)`.
@hint Нульова: `matrix(0, nrow = 2, ncol = 4)`.
@check vars=I,Z
