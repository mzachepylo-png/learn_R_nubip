# Дискретні моделі динаміки
> Рекурентні рівняння: як змінюється система від кроку до кроку.

У дискретній моделі наступний стан обчислюється з попереднього: `Nₜ₊₁ = f(Nₜ)`. Така модель у R — цикл із заздалегідь створеним вектором.

### Модель Мальтуса (експоненціальне зростання)

`Nₜ₊₁ = (1 + r)·Nₜ`

```r
r <- 0.03
N <- numeric(21)
N[1] <- 100
for (t in 1:20) N[t + 1] <- N[t] * (1 + r)
round(N[c(1, 11, 21)], 1)
plot(0:20, N, type = "b", xlab = "Рік", ylab = "Чисельність")
```

### Логістичне зростання

Зростання обмежене місткістю середовища `K`:

`Nₜ₊₁ = Nₜ + r·Nₜ·(1 − Nₜ/K)`

```r
r <- 0.4; K <- 500
N <- numeric(51); N[1] <- 10
for (t in 1:50) N[t + 1] <- N[t] + r * N[t] * (1 - N[t] / K)
plot(0:50, N, type = "l", lwd = 2, col = "darkgreen", xlab = "Крок", ylab = "N")
abline(h = K, lty = 2)
which(N >= K / 2)[1] - 1         # за скільки кроків дійшли до половини місткості
```

### Логістичне відображення і хаос

`xₜ₊₁ = r·xₜ·(1 − xₜ)`. Залежно від `r` поведінка змінюється від стійкої точки до циклів і хаосу:

```r
logistic_map <- function(r, x0, n) {
  x <- numeric(n)
  x[1] <- x0
  for (t in 2:n) x[t] <- r * x[t - 1] * (1 - x[t - 1])
  x
}
tail(logistic_map(2.8, 0.3, 200), 3)     # одна стійка точка
tail(logistic_map(3.2, 0.3, 200), 4)     # цикл періоду 2
tail(logistic_map(3.9, 0.3, 200), 4)     # хаос
```

### Матриця Леслі: вікова структура

Популяція з трьох вікових груп. Верхній рядок матриці — плідність, піддіагональ — виживання:

```r
L <- matrix(c(0, 1.5, 1.0,
              0.6, 0,   0,
              0,   0.8, 0), nrow = 3, byrow = TRUE)
N <- c(100, 50, 20)
for (t in 1:10) N <- L %*% N
round(drop(N), 1)
Re(eigen(L)$values[1])      # домінантне власне число — довгострокова швидкість зростання
```

> 💡 Якщо домінантне власне число λ > 1 — популяція зростає, λ < 1 — вимирає.

## Завдання: Логістичне відображення
Напишіть функцію `logistic_map(r, x0, n)`, яка повертає вектор із `n` значень послідовності `x[t] = r·x[t-1]·(1 − x[t-1])`, де `x[1] = x0`.
```r starter
# logistic_map <- function(r, x0, n) {
#
# }

```
```r solution
logistic_map <- function(r, x0, n) {
  x <- numeric(n)
  x[1] <- x0
  for (t in 2:n) x[t] <- r * x[t - 1] * (1 - x[t - 1])
  x
}
```
@hint Створіть вектор `numeric(n)`, запишіть `x[1] <- x0` і заповніть решту в циклі.
@check uses=function
@test is.function(logistic_map) && length(logistic_map(3.2, 0.3, 50)) == 50 && abs(tail(logistic_map(2.8, 0.3, 300), 1) - (1 - 1 / 2.8)) < 1e-6 => Для r = 2.8 послідовність має збігатися до 1 − 1/r ≈ 0.6429; довжина має дорівнювати n.
@test is.function(logistic_map) && abs(diff(tail(logistic_map(3.2, 0.3, 400), 2))) > 0.1 => Для r = 3.2 очікується цикл періоду 2 (останні два значення різні).

## Завдання: Модель Рікера
Напишіть функцію `ricker(N0, r, K, steps)`, що повертає вектор довжини `steps + 1` для моделі `N[t+1] = N[t]·exp(r·(1 − N[t]/K))`.
```r starter
# ricker <- function(N0, r, K, steps) {
#
# }

```
```r solution
ricker <- function(N0, r, K, steps) {
  N <- numeric(steps + 1)
  N[1] <- N0
  for (t in 1:steps) N[t + 1] <- N[t] * exp(r * (1 - N[t] / K))
  N
}
```
@hint Структура така сама, як у логістичного зростання, змінюється лише формула.
@check uses=function
@test is.function(ricker) && length(ricker(10, 0.5, 100, 40)) == 41 && abs(tail(ricker(10, 0.5, 100, 200), 1) - 100) < 1e-6 => Довжина має бути steps + 1, а при r = 0.5 чисельність збігається до K = 100.
