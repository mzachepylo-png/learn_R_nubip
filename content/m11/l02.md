# Диференціальні рівняння: метод Ейлера й Рунге–Кутта
> Моделі неперервної динаміки: зростання, епідемії, хижак–жертва.

Диференціальне рівняння `dy/dt = f(y)` описує швидкість зміни величини. Більшість рівнянь не розв'язуються у формулах, тому їх інтегрують чисельно.

### Метод Ейлера

Замінюємо похідну скінченною різницею: `yₙ₊₁ = yₙ + h·f(yₙ)`.

```r
f <- function(y) -0.3 * y          # розпад: dy/dt = −0.3·y
h <- 0.1; n <- 50
y <- numeric(n + 1); y[1] <- 10
for (i in 1:n) y[i + 1] <- y[i] + h * f(y[i])
c(Ейлер = y[n + 1], точно = 10 * exp(-0.3 * 5))
```

Похибка зменшується пропорційно кроку `h` (метод першого порядку). Загальна функція:

```r
euler <- function(f, y0, h, n) {
  y <- numeric(n + 1)
  y[1] <- y0
  for (i in 1:n) y[i + 1] <- y[i] + h * f(y[i])
  y
}
yE <- euler(function(y) -0.3 * y, 10, 0.1, 50)
```

### Метод Рунге–Кутта 4-го порядку

Набагато точніший при тому ж кроці:

```r
rk4 <- function(f, y0, h, n) {
  y <- numeric(n + 1)
  y[1] <- y0
  for (i in 1:n) {
    k1 <- f(y[i])
    k2 <- f(y[i] + h / 2 * k1)
    k3 <- f(y[i] + h / 2 * k2)
    k4 <- f(y[i] + h * k3)
    y[i + 1] <- y[i] + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4)
  }
  y
}
yR <- rk4(function(y) -0.3 * y, 10, 0.1, 50)
c(Ейлер = yE[51], RK4 = yR[51], точно = 10 * exp(-1.5))
```

### Системи рівнянь: модель SIR

Поділ населення `N` на вразливих S, інфікованих I та одужалих R:

`S' = −β·S·I/N`, `I' = β·S·I/N − γ·I`, `R' = γ·I`

```r
beta <- 0.3; gamma <- 0.1; N <- 1000
S <- I <- R <- numeric(161)
S[1] <- 999; I[1] <- 1; R[1] <- 0
for (t in 1:160) {
  new_inf <- beta * S[t] * I[t] / N
  rec <- gamma * I[t]
  S[t + 1] <- S[t] - new_inf
  I[t + 1] <- I[t] + new_inf - rec
  R[t + 1] <- R[t] + rec
}
matplot(0:160, cbind(S, I, R), type = "l", lty = 1, lwd = 2, col = c("blue", "red", "darkgreen"),
        xlab = "День", ylab = "Особи")
legend("right", c("S", "I", "R"), col = c("blue", "red", "darkgreen"), lty = 1, lwd = 2)
max(I); which.max(I) - 1      # пік епідемії та день піку
```

Базове репродуктивне число `R₀ = β/γ = 3`: епідемія спалахує, бо `R₀ > 1`.

### Хижак–жертва (Лотка–Вольтерра)

`x' = a·x − b·x·y` (жертви), `y' = −c·y + d·x·y` (хижаки):

```r
a <- 1; b <- 0.1; c <- 1.5; d <- 0.075
h <- 0.01; n <- 2000
x <- y <- numeric(n + 1); x[1] <- 10; y[1] <- 5
for (i in 1:n) {
  dx <- a * x[i] - b * x[i] * y[i]
  dy <- -c * y[i] + d * x[i] * y[i]
  x[i + 1] <- x[i] + h * dx
  y[i + 1] <- y[i] + h * dy
}
plot(x, y, type = "l", xlab = "Жертви", ylab = "Хижаки")   # фазовий портрет
```

> ⚠️ Метод Ейлера для системи Лотки–Вольтерра повільно «розкручує» цикл. Менший крок або RK4 дають кращу точність.

Напишіть функцію `euler(f, y0, h, n)`, що повертає вектор із `n + 1` значень методу Ейлера для скалярного рівняння `y' = f(y)`.

## Завдання: Метод Рунге–Кутта
Напишіть функцію `rk4(f, y0, h, n)` для скалярного рівняння `y' = f(y)` за схемою RK4 (коефіцієнти `k1…k4`).
```r starter
# rk4 <- function(f, y0, h, n) {
#
# }

```
```r solution
rk4 <- function(f, y0, h, n) {
  y <- numeric(n + 1)
  y[1] <- y0
  for (i in 1:n) {
    k1 <- f(y[i])
    k2 <- f(y[i] + h / 2 * k1)
    k3 <- f(y[i] + h / 2 * k2)
    k4 <- f(y[i] + h * k3)
    y[i + 1] <- y[i] + h / 6 * (k1 + 2 * k2 + 2 * k3 + k4)
  }
  y
}
```
@hint `y[i+1] = y[i] + h/6 · (k1 + 2k2 + 2k3 + k4)`.
@check uses=function
@test is.function(rk4) && abs(rk4(function(y) -0.3 * y, 10, 0.1, 50)[51] - 10 * exp(-1.5)) < 1e-6 => RK4 має відтворювати точний розв'язок 10·e^(−1.5) із точністю 10⁻⁶.

## Завдання: Епідемія SIR
Змоделюйте модель SIR методом Ейлера з кроком 1 день на 160 днів: `β = 0.3`, `γ = 0.1`, `N = 1000`, `S(0) = 999`, `I(0) = 1`, `R(0) = 0`. Створіть вектори `S`, `I`, `R` довжини 161, а також `peak_I` — максимум `I`, і `peak_day` — день піку (початок — день 0).
```r starter
# beta <- 0.3; gamma <- 0.1; N <- 1000
# S <- I <- R <- numeric(161)
# ...

```
```r solution
beta <- 0.3
gamma <- 0.1
N <- 1000
S <- I <- R <- numeric(161)
S[1] <- 999
I[1] <- 1
R[1] <- 0
for (t in 1:160) {
  new_inf <- beta * S[t] * I[t] / N
  rec <- gamma * I[t]
  S[t + 1] <- S[t] - new_inf
  I[t + 1] <- I[t] + new_inf - rec

```
@hint Нових інфікованих за день: `beta * S[t] * I[t] / N`, одужань: `gamma * I[t]`.

@check vars=peak_I,peak_day,S,I,R
