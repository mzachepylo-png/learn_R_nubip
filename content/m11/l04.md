# Оптимізація та підгонка моделей
> optim, найменші квадрати, максимальна правдоподібність і градієнтний спуск.

### optim — універсальний мінімізатор

`optim(start, f)` мінімізує функцію від вектора параметрів. Метод за замовчуванням — Нелдера–Міда; для гладких функцій краще `"BFGS"`.

```r
rosen <- function(p) 100 * (p[2] - p[1]^2)^2 + (1 - p[1])^2
res <- optim(c(-1.2, 1), rosen, method = "BFGS")
round(res$par, 3)       # справжній мінімум у (1, 1)
res$value
```

### Метод найменших квадратів «вручну»

```r
x <- c(1, 2, 3, 4, 5)
y <- c(2.2, 4.1, 6.2, 7.9, 10.1)
sse <- function(b) sum((y - (b[1] + b[2] * x))^2)
fit <- optim(c(0, 0), sse, method = "BFGS")
fit$par
coef(lm(y ~ x))         # збігається з lm
```

### Максимальна правдоподібність

Оцінка параметрів — максимізація (мінімізація мінус-)логарифма правдоподібності:

```r
set.seed(1)
t_fail <- rexp(50, rate = 0.2)       # терміни відмов
nll <- function(rate) -sum(dexp(t_fail, rate, log = TRUE))
opt <- optimize(nll, c(0.001, 5))
opt$minimum
1 / mean(t_fail)                      # аналітична оцінка MLE
```

### Градієнтний спуск

Ідея: рухатися проти градієнта функції втрат. Для регресії `y ≈ b₀ + b₁x` з MSE:

```r
b <- c(0, 0); alpha <- 0.01
for (i in 1:20000) {
  err <- (b[1] + b[2] * x) - y
  grad <- c(mean(err), mean(err * x))   # половина градієнта MSE
  b <- b - alpha * grad
}
b
```

Занадто великий `alpha` призводить до розбіжності, а занадто малий — до повільного руху.

### Практичне застосування: оптимальна доза добрива

Відгук урожайності на азот: `y(N) = 2 + 0.08·N − 0.0002·N²` (т/га). Ціна зерна 300 дол/т, азоту — 0.8 дол/кг:

```r
profit <- function(N) 300 * (2 + 0.08 * N - 0.0002 * N^2) - 0.8 * N
optimize(profit, c(0, 300), maximum = TRUE)$maximum    # аналітично: 193.33
```

### Підгонка логістичної кривої

```r
t <- 0:10
N <- round(500 / (1 + 49 * exp(-0.5 * t)), 1)
fit <- nls(N ~ K / (1 + A * exp(-r * t)), start = list(K = 400, A = 40, r = 0.3))
round(coef(fit), 2)
```

## Завдання: Градієнтний спуск
Реалізуйте градієнтний спуск для регресії `y ≈ b[1] + b[2]·x` із початку `b = c(0, 0)`, `alpha = 0.01`, 20 000 ітерацій: `err = b[1] + b[2]*x − y`, `grad = c(mean(err), mean(err*x))`, `b = b − alpha·grad`. Результат — `b`.
```r setup
x <- c(1, 2, 3, 4, 5)
y <- c(2.2, 4.1, 6.2, 7.9, 10.1)
```
```r starter
# b <- c(0, 0); alpha <- 0.01
# for (i in 1:20000) { ... }

```
```r solution
b <- c(0, 0)
alpha <- 0.01
for (i in 1:20000) {
  err <- (b[1] + b[2] * x) - y
  grad <- c(mean(err), mean(err * x))
  b <- b - alpha * grad
}
```
@hint Градієнт за `b[2]` містить множник `x`: `mean(err * x)`.
@check uses=for
@test length(b) == 2 && all(abs(b - unname(coef(lm(y ~ x)))) < 0.01) => b має наближатися до коефіцієнтів МНК (≈ 0.15 та 1.97).
