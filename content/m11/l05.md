### Випадкове блукання

Кожен крок — ±1 з рівною ймовірністю:

```r
set.seed(1)
walk <- cumsum(sample(c(-1, 1), 1000, replace = TRUE))
plot(walk, type = "l", xlab = "Крок", ylab = "Положення")
abline(h = 0, lty = 2)
c(кінець = walk[1000], максимум = max(walk))
```

### Задача про розорення гравця

Починаємо з капіталом 10; кожен раунд виграємо 1 з імовірністю `p`, інакше програємо 1. Гра триває, доки капітал не досягне 0 або мети 20:

```r
play <- function(start, goal, p) {
  money <- start
  while (money > 0 && money < goal) {
    money <- money + if (runif(1) < p) 1 else -1
  }
  money == goal
}
set.seed(2)
mean(replicate(2000, play(10, 20, 0.5)))      # теоретично 0.5
mean(replicate(2000, play(10, 20, 0.45)))     # навіть невеликий недолік різко знижує шанси
```

### Імітація ланцюга Маркова

```r
P <- matrix(c(0.9, 0.1,
              0.4, 0.6), nrow = 2, byrow = TRUE)
set.seed(3)
n <- 5000
state <- numeric(n); state[1] <- 1
for (t in 2:n) state[t] <- sample(1:2, 1, prob = P[state[t - 1], ])
mean(state == 1)         # частка часу в стані 1 → стаціонарна ймовірність 0.8
```

### Черга M/M/1

Клієнти приходять із інтенсивністю λ, обслуговуються з інтенсивністю μ. Час очікування наступного клієнта обчислюють рекурентно (рекурсія Ліндлі): `Wₙ₊₁ = max(0, Wₙ + Sₙ − Aₙ₊₁)`:

```r
set.seed(4)
n <- 100000; lambda <- 0.8; mu <- 1
A <- rexp(n, lambda)      # інтервали між приходами
S <- rexp(n, mu)          # тривалості обслуговування
W <- numeric(n)
for (i in 2:n) W[i] <- max(0, W[i - 1] + S[i - 1] - A[i])
mean(W)                   # теорія: ρ / (μ − λ) = 4
```

### Популяція у випадковому середовищі

`N(t+1) = N(t)·exp(ξ)`, де `ξ ~ N(μ, σ²)`: навіть при додатному середньому зростанні існує ризик вимирання чи сильного спаду.

```r
set.seed(5)
decline <- replicate(2000, {
  N <- 100
  for (t in 1:50) N <- N * exp(rnorm(1, 0.02, 0.15))
  N < 50
})
mean(decline)
```

## Завдання: Розорення гравця
Напишіть функцію `play(start, goal, p)`, що імітує одну гру (див. теорію) і повертає `TRUE`, якщо гравець досяг мети. Потім із `set.seed(2)` оцініть імовірність успіху при `start = 10`, `goal = 20`, `p = 0.5` на 2000 іграх: змінна `p_win`.
```r starter
# play <- function(start, goal, p) {
#
# }
# set.seed(2)
# p_win <- ...

```
```r solution
play <- function(start, goal, p) {
  money <- start
  while (money > 0 && money < goal) {
    money <- money + if (runif(1) < p) 1 else -1
  }
```

## Завдання: Імітація ланцюга Маркова
Для матриці переходів `P` змоделюйте 5000 кроків ланцюга з початку у стані 1 (`set.seed(3)`; наступний стан — `sample(1:2, 1, prob = P[попередній, ])`). Вектор станів — `state`, частка часу в стані 1 — `freq1`.

```r setup
P <- matrix(c(0.9, 0.1,
```

## Завдання: Черга M/M/1
Змоделюйте чергу з `λ = 0.8`, `μ = 1` для 100 000 клієнтів (`set.seed(4)`): `A <- rexp(n, lambda)`, `S <- rexp(n, mu)`, `W[i] = max(0, W[i−1] + S[i−1] − A[i])`, `W[1] = 0`. Середній час очікування — `w_mean` (теорія: 4).
```r starter
# set.seed(4)
# n <- 100000; lambda <- 0.8; mu <- 1
# A <- ...
# S <- ...
# W <- numeric(n)
# for (...) ...
# w_mean <- mean(W)

```
```r solution
set.seed(4)
n <- 100000
lambda <- 0.8
mu <- 1
A <- rexp(n, lambda)
S <- rexp(n, mu)
W <- numeric(n)
for (i in 2:n) W[i] <- max(0, W[i - 1] + S[i - 1] - A[i])
w_mean <- mean(W)
```
@hint Цикл починається з `i = 2`, бо `W[1] = 0`.
@check uses=rexp,max
@test abs(w_mean - 4) < 1 => Середній час очікування має бути близьким до теоретичного 4.

## Завдання: Ризик спаду
Популяція стартує зі 100 особин; щороку `N ← N·exp(ξ)`, `ξ ~ N(0.02, 0.15²)`. Оцініть (2000 симуляцій за 50 років, `set.seed(5)`) імовірність того, що кінцева чисельність буде нижчою за 50: змінна `p_decline`.
```r starter
# set.seed(5)
# p_decline <- ...

```
```r solution
set.seed(5)
decline <- replicate(2000, {
  N <- 100
  for (t in 1:50) N <- N * exp(rnorm(1, 0.02, 0.15))
  N < 50
})
p_decline <- mean(decline)
```
@hint Усередині `replicate` — цикл за 50 років, що повертає `N < 50`.
@check uses=replicate
@test exists("p_decline") && abs(p_decline - .sol$p_decline) < 0.05 && p_decline > 0 => Імовірність спаду має бути близькою до очікуваної (кілька відсотків).

## Тест: Стаціонарний розподіл
Що описує стаціонарний розподіл ланцюга Маркова?
- [ ] початковий стан
- [x] частку часу, яку ланцюг у довгостроковій перспективі проводить у кожному стані
- [ ] ймовірність переходу за один крок
- [ ] кількість станів
@explain Стаціонарний розподіл `π` задовольняє `π·P = π`; для ергодичного ланцюга до нього збігаються як розподіл станів, так і частоти відвідувань.
