### Корені рівнянь

`uniroot(f, interval)` знаходить корінь на відрізку, на кінцях якого `f` має різні знаки:

```r
f <- function(x) x^3 - x - 2
res <- uniroot(f, c(1, 2), tol = 1e-10)
res$root
f(res$root)
```

**Метод Ньютона** використовує похідну: `xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ)`. Збігається дуже швидко, якщо початкове наближення добре:

```r
newton <- function(f, df, x0, tol = 1e-10, max_iter = 50) {
  x <- x0
  for (i in 1:max_iter) {
    x_new <- x - f(x) / df(x)
    if (abs(x_new - x) < tol) return(x_new)
    x <- x_new
  }
  x
}
newton(function(x) x^2 - 2, function(x) 2 * x, 1)    # √2
```

### Інтегрування

```r
integrate(dnorm, -1.96, 1.96)           # ≈ 0.95
integrate(function(x) x^2, 0, 3)$value  # 9
integrate(dnorm, -Inf, Inf)             # нескінченні межі
```

Власні реалізації: **метод трапецій** та **формула Сімпсона**.

```r
trapz <- function(x, y) sum(diff(x) * (head(y, -1) + tail(y, -1)) / 2)
x <- seq(0, 1, length.out = 1001)
trapz(x, x^2)                           # ≈ 1/3

simpson <- function(f, a, b, n = 100) {   # n — парне
  x <- seq(a, b, length.out = n + 1)
  h <- (b - a) / n
  w <- c(1, rep(c(4, 2), length.out = n - 1), 1)
  h / 3 * sum(w * f(x))
}
simpson(sin, 0, pi)                     # ≈ 2
```

### Оптимізація функції однієї змінної

```r
profit <- function(x) -2 * x^2 + 40 * x - 50
opt <- optimize(profit, c(0, 30), maximum = TRUE)
opt$maximum; opt$objective
curve(profit, 0, 30); abline(v = opt$maximum, lty = 2, col = "red")
```

### Чисельне диференціювання

```r
num_deriv <- function(f, x, h = 1e-6) (f(x + h) - f(x - h)) / (2 * h)
num_deriv(sin, 0)                       # cos(0) = 1
```

## Завдання: Метод Ньютона
Напишіть функцію `newton(f, df, x0, tol = 1e-10)`, що ітеративно обчислює `x − f(x)/df(x)`, поки зміна не стане меншою за `tol` (не більше 100 ітерацій), і повертає наближення кореня.
```r starter
# newton <- function(f, df, x0, tol = 1e-10) {
#
# }

```
```r solution
newton <- function(f, df, x0, tol = 1e-10) {
  x <- x0
  for (i in 1:100) {
    x_new <- x - f(x) / df(x)
    if (abs(x_new - x) < tol) return(x_new)
    x <- x_new
  }
  x
}
```
@hint Зупиняйтеся, коли `abs(x_new - x) < tol`.
@check uses=function

@test is.function(newton) && abs(newton(function(x) cos(x) - x, function(x) -sin(x) - 1, 1) - 0.7390851) < 1e-6 => Корінь cos(x) − x ≈ 0.739085.

## Завдання: Метод трапецій
Напишіть функцію `trapz(x, y)`, що обчислює інтеграл методом трапецій за вузлами `x` і значеннями `y`.
```r starter
# trapz <- function(x, y) {
#
# }

```
```r solution
trapz <- function(x, y) {
  sum(diff(x) * (head(y, -1) + tail(y, -1)) / 2)
}
```
@hint Площа однієї трапеції: `(y[i] + y[i+1]) / 2 * (x[i+1] - x[i])`.
@check uses=function

@test is.function(trapz) && abs(trapz(c(0, 2), c(1, 5)) - 6) < 1e-12 => Для лінійної функції результат точний: trapz(c(0, 2), c(1, 5)) = 6.

## Завдання: Формула Сімпсона
Напишіть функцію `simpson(f, a, b, n = 100)` (n — парне), що наближено обчислює `∫ₐᵇ f(x) dx` за формулою Сімпсона з вагами 1, 4, 2, 4, …, 4, 1.
```r starter
# simpson <- function(f, a, b, n = 100) {
#
# }

```
```r solution
simpson <- function(f, a, b, n = 100) {
  x <- seq(a, b, length.out = n + 1)
  h <- (b - a) / n
  w <- c(1, rep(c(4, 2), length.out = n - 1), 1)
  h / 3 * sum(w * f(x))
}
```
@hint Ваги: `c(1, rep(c(4, 2), length.out = n - 1), 1)`.
@check uses=function
@test is.function(simpson) && abs(simpson(sin, 0, pi) - 2) < 1e-6 => ∫₀^π sin x dx = 2.
@test is.function(simpson) && abs(simpson(function(x) x^3, 0, 2) - 4) < 1e-10 => Формула Сімпсона точна для кубічних многочленів: ∫₀² x³ dx = 4.
