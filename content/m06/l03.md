# Робота з текстом
> Склеювання, форматування, пошук і заміна в рядках.

### Основи

```r
s <- "Аналіз даних в R"
nchar(s)                    # довжина
toupper(s); tolower(s)
substr(s, 1, 6)             # символи з 1-го по 6-й
trimws("   зайві пробіли  ")
rev(strsplit("a,b,c", ",")[[1]])
```

### paste та sprintf

`paste()` склеює, `sprintf()` форматує за шаблоном (як `printf` у C):

```r
paste("поле", 1:3)
paste0("поле", 1:3)
paste(c("A", "B"), collapse = " + ")      # в один рядок

name <- "A1"; y <- 5.678
sprintf("Поле %s: %.1f т/га", name, y)
sprintf("%05d", 42)                       # 00042
sprintf("%6.2f%%", 12.3456)               # 12.35% (подвійний % — літерал)
```

### Розбиття рядків

```r
code <- "UA-12-W"
strsplit(code, "-")[[1]]
parts <- strsplit(c("UA-12-W", "PL-07-S"), "-")
sapply(parts, `[`, 2)                     # другий елемент кожного
```

### Пошук і заміна

```r
x <- c("5,4", "6,1", "4,9")
gsub(",", ".", x)                         # замінити всі входження
as.numeric(gsub(",", ".", x))

codes <- c("W-01", "S-02", "W-03", "M-04")
grepl("^W", codes)                        # чи починається з W
codes[grepl("^W", codes)]
startsWith(codes, "W")
sub("-.*", "", codes)                     # видалити все від дефіса
```

### Регулярні вирази (коротко)

| Шаблон | Значення |
|---|---|
| `^` , `$` | початок, кінець рядка |
| `\\d` | цифра |
| `.` | будь-який символ |
| `*`, `+`, `?` | 0+ , 1+, 0 або 1 повторень |
| `[abc]`, `[0-9]` | клас символів |
| `(...)` | група (посилання `\\1`) |

```r
files <- c("report_2021.csv", "data_2023_v2.csv")
sub(".*(\\d{4}).*", "\\1", files)          # витягнути 4 цифри
```

> 💡 У рядках R зворотний слеш треба подвоювати: регулярний вираз `\d` записується як `"\\d"`.

## Завдання: Рік із назви файлу
З назв файлів витягніть чотиризначний рік як число: вектор `years`.
```r setup
files <- c("report_2021.csv", "data_2023_v2.csv", "obs2019final.txt")
```
```r starter

```

@hint Шаблон з групою: `".*(\\d{4}).*"`, заміна — `"\\1"`.
@hint Не забудьте обгорнути результат у `as.integer()`.
@check vars=years

## Завдання: Прибирання тексту
Приведіть назви в `raw` до єдиного вигляду: без пробілів по краях і малими літерами. Результат — `clean`.
```r setup
raw <- c("  Пшениця", "ЯЧМІНЬ ", " Соя  ")
```
```r starter
# clean <- ...

```
```r solution
clean <- tolower(trimws(raw))
```
@hint Поєднайте `trimws()` і `tolower()`.
@check vars=clean
