# Пропуски, дублікати та викиди
> Брудні дані — норма. Навчимося знаходити й виправляти типові проблеми.

```r
df <- data.frame(
  id   = 1:7,
  temp = c(21.5, NA, 19.8, 23.1, NA, 22.0, 21.5),
  hum  = c(60, 55, NA, 58, 62, 61, 60)
)
df
```

### Виявлення пропусків

```r
is.na(df$temp)
anyNA(df)
colSums(is.na(df))           # скільки NA у кожному стовпці
mean(is.na(df$temp))         # частка пропусків
```

### Видалення неповних рядків

```r
complete.cases(df)
df[complete.cases(df), ]
na.omit(df)
```

### Заповнення (імпутація)

```r
df$temp[is.na(df$temp)] <- mean(df$temp, na.rm = TRUE)    # середнім
df$hum[is.na(df$hum)] <- median(df$hum, na.rm = TRUE)     # медіаною
df
```

> ⚠️ `NA == NA` дає `NA`, а не `TRUE`. Перевіряйте пропуски лише через `is.na()`.

### Дублікати

```r
d <- data.frame(a = c(1, 2, 2, 3), b = c("x", "y", "y", "z"))
duplicated(d)
d[!duplicated(d), ]
unique(d)
```

### Викиди за правилом Тьюкі (IQR)

Значення вважають викидом, якщо воно менше `Q1 − 1.5·IQR` або більше `Q3 + 1.5·IQR`:

```r
x <- c(5.1, 5.4, 4.9, 5.6, 5.2, 12.4, 5.0, 5.3)
q <- quantile(x, c(0.25, 0.75))
iqr <- IQR(x)
low <- q[1] - 1.5 * iqr
high <- q[2] + 1.5 * iqr
x[x < low | x > high]
boxplot.stats(x)$out      # те саме вбудованою функцією
```

## Завдання: Викиди
Знайдіть у векторі `x` викиди за правилом 1.5·IQR (значення поза `[Q1 − 1.5·IQR, Q3 + 1.5·IQR]`) — вектор `outliers`.
```r setup
x <- c(5.1, 5.4, 4.9, 5.6, 5.2, 12.4, 5.0, 5.3, 1.1)
```
```r starter
# q <- quantile(...)
# outliers <- ...

```
```r solution
q <- quantile(x, c(0.25, 0.75))
iqr <- q[2] - q[1]
outliers <- x[x < q[1] - 1.5 * iqr | x > q[2] + 1.5 * iqr]
```
@hint `quantile(x, c(0.25, 0.75))` дає Q1 і Q3; `IQR = Q3 − Q1`.
@check vars=outliers
