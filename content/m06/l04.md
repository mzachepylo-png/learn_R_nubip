# Дати та час
> Дати як окремий тип: різниці, послідовності, групування за місяцями.

Дати зберігаються у класі `Date` (кількість днів від 1970-01-01). Рядок перетворюють функцією `as.Date()` із вказанням формату:

```r
d <- as.Date("2024-05-17")           # ISO-формат — без format
d2 <- as.Date("17.05.2024", format = "%d.%m.%Y")
d == d2
class(d)
as.numeric(d)
```

### Коди формату

| Код | Значення | Код | Значення |
|---|---|---|---|
| `%Y` | рік (2024) | `%d` | день місяця |
| `%y` | рік (24) | `%m` | місяць (01–12) |
| `%j` | день року | `%u` | день тижня (1 = пн) |

```r
format(d, "%d.%m.%Y")
format(d, "%Y-%m")
as.integer(format(d, "%j"))
```

> 💡 Назви місяців і днів тижня (`%B`, `%A`) залежать від мови системи й у цьому середовищі виводяться англійською, тому ми працюємо з номерами.

### Арифметика дат

```r
sowing <- as.Date("2024-04-20")
harvest <- as.Date("2024-08-15")
harvest - sowing
as.numeric(harvest - sowing)         # кількість днів
difftime(harvest, sowing, units = "weeks")
sowing + 30
```

### Послідовності та групування

```r
seq(as.Date("2024-01-01"), by = "month", length.out = 4)
seq(as.Date("2024-01-01"), as.Date("2024-01-10"), by = "3 days")

obs <- as.Date(c("2024-03-05", "2024-03-20", "2024-04-02", "2024-04-15", "2024-04-28"))
table(format(obs, "%Y-%m"))          # скільки спостережень за місяць
diff(obs)                            # інтервали між спостереженнями
```

## Завдання: Дата в українському форматі
Перетворіть рядок `s` у дату `d` (формат «день.місяць.рік»).
```r setup
s <- "17.05.2024"
```
```r starter
# d <- as.Date(...)

```
```r solution
d <- as.Date(s, format = "%d.%m.%Y")
```
@hint Формат: `"%d.%m.%Y"`.
@check vars=d

## Завдання: Тривалість вегетації
Обчисліть кількість днів між сівбою `sowing` та збором `harvest` як число — змінна `days`.
```r setup
sowing <- as.Date("2024-04-20")
harvest <- as.Date("2024-08-15")
```
```r starter
# days <- ...

```
```r solution
days <- as.numeric(harvest - sowing)
```
@hint Різниця дат — об'єкт `difftime`; `as.numeric()` робить із нього число.
@check vars=days

## Завдання: Щомісячні дати
Створіть вектор `months6` із першими числами шести місяців, починаючи з 1 січня 2024 (`seq` з `by = "month"`).

```r starter
# months6 <- seq(...)

```
```r solution
months6 <- seq(as.Date("2024-01-01"), by = "month", length.out = 6)
```
@hint `seq(початок, by = "month", length.out = 6)`.
@check vars=months6

## Завдання: Спостереження за місяцями
Підрахуйте, скільки спостережень припадає на кожен місяць, і виведіть таблицю (використайте `format(obs, "%Y-%m")` та `table`).
```r setup
obs <- as.Date(c("2024-03-05", "2024-03-20", "2024-04-02", "2024-04-15", "2024-04-28"))
```
```r starter
# table(...)

```
```r solution
table(format(obs, "%Y-%m"))
```
@hint Спершу перетворіть дати на рядки «рік-місяць».
@check output uses=table,format

## Завдання: Інтервали
Обчисліть числовий вектор `gaps` — кількість днів між сусідніми датами спостережень.
```r setup
obs <- as.Date(c("2024-03-05", "2024-03-20", "2024-04-02", "2024-04-15", "2024-04-28"))
```

```r starter
# gaps <- ...
```

```r solution
gaps <- as.numeric(diff(obs))
```
