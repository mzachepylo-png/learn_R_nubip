# Перетворення та реструктуризація даних
> Групові стовпці, довгий і широкий формати, ковзне середнє, конвеєри.

### ave — групова статистика поруч із рядками

`ave(x, група, FUN)` повертає вектор тієї ж довжини, де кожне значення замінене груповою статистикою (за замовчуванням — середнім):

```r
df <- data.frame(g = c("A", "A", "B", "B", "B"), y = c(4, 6, 10, 12, 14))
df$g_mean <- ave(df$y, df$g)
df$dev <- df$y - df$g_mean
df$z <- ave(df$y, df$g, FUN = function(v) (v - mean(v)) / sd(v))
df
```

### Широкий → довгий формат

Для аналізу й графіків зручніший **довгий** формат: одне спостереження — один рядок.

```r
wide <- data.frame(field = c("A", "B"), y2021 = c(5.1, 6.0), y2022 = c(5.4, 6.3), y2023 = c(5.0, 6.5))
long <- data.frame(
  field = rep(wide$field, times = 3),
  year  = rep(2021:2023, each = nrow(wide)),
  yield = unlist(wide[, -1], use.names = FALSE)
)
long
```

### Ковзне середнє

```r
x <- c(3, 5, 4, 8, 7, 9, 12)
ma <- stats::filter(x, rep(1/3, 3), sides = 2)    # центроване, вікно 3
as.numeric(ma)
```

Перший і останній елементи — `NA`, бо для них немає повного вікна.

### Частки та ранги

```r
sales <- c(A = 120, B = 80, C = 200)
round(100 * sales / sum(sales), 1)     # відсотки
rank(-sales)                           # місце за спаданням
cumsum(sort(sales, decreasing = TRUE)) / sum(sales)   # Парето
```

### Конвеєр із |>

Нативний пайп передає результат як **перший** аргумент наступної функції:

```r
subset(mtcars, cyl == 4)$mpg |> mean()
mtcars |> subset(hp > 200, select = c(mpg, hp)) |> head(3)
```

## Завдання: Ковзне середнє
Обчисліть центроване ковзне середнє з вікном 3 для `x` — числовий вектор `ma` (функція `stats::filter`; перший і останній елементи будуть `NA`).
```r setup
x <- c(3, 5, 4, 8, 7, 9, 12)
```
```r starter
# ma <- as.numeric(stats::filter(...))

```
```r solution
ma <- as.numeric(stats::filter(x, rep(1 / 3, 3), sides = 2))
```
@hint Ваги вікна: `rep(1/3, 3)`.
@check

## Тест: Результат ave
Що повертає `ave(y, g)`?
- [ ] по одному значенню на кожну групу
- [x] вектор тієї ж довжини, що й `y`, де кожне значення — середнє його групи
- [ ] дата-фрейм зі стовпцями `g` та `y`
- [ ] кількість елементів у групі
@explain На відміну від `tapply`/`aggregate`, `ave` *не згортає* дані: результат зручно додавати як новий стовпець.
