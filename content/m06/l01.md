# Імпорт та експорт даних
> Прочитайте таблицю з CSV-тексту чи файлу та перевірте, що завантажилось правильно.

Дані зазвичай зберігають у файлах CSV (*comma-separated values*). Основна функція — `read.csv()`:

```r static
# на вашому комп'ютері:
df <- read.csv("harvest.csv")
df <- read.csv("harvest.csv", encoding = "UTF-8")
```

У браузері немає доступу до вашої файлової системи, тому в курсі ми читаємо дані з **текстових рядків** через аргумент `text =` — синтаксис такий самий:

```r
csv_text <- "поле,культура,урожайність
A,пшениця,5.4
B,ячмінь,4.8
C,пшениця,6.1
D,соя,2.9"
df <- read.csv(text = csv_text)
df
str(df)
```

### Роздільники та десяткові коми

Українські версії Excel зберігають CSV з роздільником `;` і комою як десятковим знаком. Для цього є `read.csv2()` (або `sep = ";", dec = ","`):

```r
txt <- "поле;урожайність
A;5,4
B;4,8"
read.csv2(text = txt)
read.csv(text = txt, sep = ";", dec = ",")
```

### Пропущені значення

Часто пропуски позначають символами `-`, `n/a` тощо. Скажіть R, що це `NA`:

```r
raw <- "id,temp
1,21.5
2,-
3,19.8"
d <- read.csv(text = raw, na.strings = c("-", "n/a", ""))
d
mean(d$temp, na.rm = TRUE)
```

### Запис і читання назад

```r
tmp <- tempfile(fileext = ".csv")
write.csv(df, tmp, row.names = FALSE)    # без нумерації рядків
readLines(tmp)
back <- read.csv(tmp)
identical(back, df)
```

> 💡 Завжди після імпорту виконуйте `str()`, `head()` та `summary()` — так ви швидко побачите неправильні типи й дивні значення.

## Завдання: Крапка з комою
Дані збережено в українському форматі (роздільник `;`, десяткова кома). Прочитайте їх у `df2` функцією `read.csv2()`.
```r setup
txt <- "поле;урожайність;вологість
A;5,4;14,2
B;4,8;13,9
C;6,1;15,0"
```
```r starter
# df2 <- ...

```
```r solution
df2 <- read.csv2(text = txt)
```
@hint `read.csv2` уже налаштована на `;` та `,`.
@check vars=df2 uses=read.csv2

## Завдання: Позначення пропусків
У даних пропуски записані як `-`. Прочитайте їх у `d` так, щоб `-` та порожні клітинки стали `NA`, і обчисліть середню температуру ігноруючи пропуски — у змінну `m`.
```r setup
raw <- "id,temp
1,21.5
2,-
3,19.8
4,
5,23.1"
```
```r starter
# d <- read.csv(...)
# m <- ...

```
```r solution
d <- read.csv(text = raw, na.strings = c("-", ""))
m <- mean(d$temp, na.rm = TRUE)
```
@hint Аргумент `na.strings = c("-", "")`.
@check vars=d,m
